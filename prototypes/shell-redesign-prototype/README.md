# 首页重塑：结构与状态原型

2026-11-07。**待评估、可丢弃的设计实验，不是已接受的产品决策。**

问题：游戏操作放在底部（A）还是固定侧栏（B），哪一种能同时兼顾日常启动、维护状态和壁纸表现？两种方案使用相同内容与状态。

## 打开

直接打开本目录的 `index.html`，或在仓库根目录运行：

```powershell
python -m http.server 18764 --bind 127.0.0.1
```

访问：

- A：<http://127.0.0.1:18764/prototypes/shell-redesign-prototype/index.html?variant=A>
- B：<http://127.0.0.1:18764/prototypes/shell-redesign-prototype/index.html?variant=B>
- 结构图：增加 `&page=map`。
- 状态清单：增加 `&page=states`。

底部按钮或左右箭头切换方案；聚焦表单时不截获方向键。方案、游戏状态、公告状态、主题和当前资料页会写入 URL，其他演示开关只在内存中生效。没有持久化与实际业务调用。

## 三项交付

1. **全界面结构图**：页面顶部「界面结构」。首启向导 → 主壳 → 游戏 / 配置 / 支持三条路径；标注共同覆盖层及独立崩溃窗口。
2. **关键状态清单**：页面顶部「关键状态」。11 个游戏场景、独立公告失败，以及设置、资源、自更新、卸载等表面需要补齐的状态。
3. **两个首页原型**：A 为壁纸画布与底部操作面；B 为壁纸内容区与固定右侧任务面。结构不同，数据相同。

## 试用顺序

1. 在「可启动」下切换 A/B，比较启动入口和壁纸裁切。
2. 切换「未安装」「下载中」「下载失败」，比较操作区稳定性与信息量。
3. 下载中点击暂停 / 继续 / 停止。启动后手动切换「运行中」或「启动失败」。演示不会自动推演后台结果。
4. 设为「公告加载失败」，确认就绪游戏仍可启动。
5. 检查深色、纯白 / 纯黑壁纸压力场景及 150% 任务文字；灰阶开关用于检查层级。
6. 用 Tab、Enter 和 ESC 操作。管理菜单、结构占位对话框可打开；不执行文件、网络或进程操作。

## 设计边界与待决问题

- 延续现有 M3 语义和浅深色中性令牌。主色在 HTML 内固定为 `Launcher.Text.Info` / `Launcher.Color.Info.Background` 配对，仅作示意；未复制动态 HCT 配色管线。
- 令牌来源：`src/Cafe.Launcher/App.axaml`；网页映射使用 8 DIP 控件圆角、16 DIP 表面圆角，以及现有间距尺度。网页的布局尺寸是试验参数，不是新的生产令牌。
- 复用仓库内置壁纸与图标，不新增网络资产。公告、路径、速度和进度均为显式演示数据。
- 设置、资源和帮助入口只展示职责占位，不声称完成这些页面的视觉重设计。
- B 的集中帮助入口为设计建议；诊断面板继续保留现有 Debug 约束。
- A/B 的共同待检验项：公告是否遮挡人物、侧栏是否挤压壁纸、长状态文案是否应折行或展开、只显示启动按钮的现有偏好如何适配新版布局。
- 150% 开关放大任务与公告正文，用于发现密度问题；不等于完整 OS 文字缩放或四语言验证。窄网页的堆叠只是方便浏览原型，不提议新增移动端产品。
- 下一步只在选定结构后做真实 Avalonia 原型，验证原生 SplitButton、焦点陷阱、四语言、DPI、视频背景和真实状态接线。
- 生产逻辑没有变化，因此本轮不修改领域契约、设计规范或中英文用户操作文档。原型选型后再记录决定与受影响文档。

## 原型走查（2026-11-07）

- Chromium 实际渲染：1280 / 1024 浏览器宽度 × A/B × 浅/深主题 × 100%/150% 任务文字 × 11 游戏状态，共 176 组合。未发现欢迎区与公告重叠、应用横向溢出或操作按钮区域横向溢出。
- 修正过 A 的低高度拥挤：壁纸区高度不足 450 px 时欢迎区只保留游戏标识。B 在部分 150% 状态下允许侧栏纵向滚动，是当前原型的可见取舍。
- 375 px 浏览器下检查完整页面，无页面横向溢出；此布局仅方便浏览原型。
- 实际点击检查：暂停/继续、停止确认与取消、安装演示、公告失败时启动、管理菜单 ESC、对话框关闭后焦点返回、方向键切换方案、URL 刷新和直接打开本地文件。
- 已目视检查浅色 A/B、深色下载态、150% 失败态、窄屏与结构图截图；检查期间无页面 JavaScript 异常。
- 未验证：真实 Avalonia 模板、四语言、OS 文字缩放与 DPI、视频背景、真实下载或启动结果、完整 AA 对比度审计。
