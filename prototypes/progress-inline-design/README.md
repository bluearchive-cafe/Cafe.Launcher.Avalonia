# 主界面任务进度设计稿

2026-11-08，第二版已确认并落实到启动器。根据反馈缩小信息量与尺寸，让进度卡片悬浮在主界面右下角拆分按钮上方。

这是已采纳方向的 HTML 交互稿，使用演示数据；不会操作游戏、写入设置或请求网络。生产实现以 `src/` 为准；行为契约见 [CONTEXT.md](../../CONTEXT.md#游戏任务对话框)，决策见 [ADR-057 的 2026-11-08 修订](../../docs/design/adr/ADR-057-统一操作面板与任务对话框.md)。

后续生产修订（2026-11-08）：按用户要求移除卡片折叠与文件详情列表，下载直接显示已下载大小／总大小和速度，暂停、停止、日志与重试直接可用，不显示剩余时间。以下 HTML 与两版浏览器验证保留为历史记录，现行外观以生产截图和 ADR-057 后续修订为准。

## 打开

直接用浏览器打开本目录的 `index.html`，无需安装依赖。保留它在仓库内的位置，使相对路径能读取已有壁纸与图标。也可以在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

访问 [设计稿](http://127.0.0.1:8765/prototypes/progress-inline-design/)。

URL 参数可固定截图状态，例如 `?task=repair&state=verifying&theme=dark&details=1&size=compact&scale=150`。上方工具栏修改状态时同步更新 URL；所有交互状态仅保存在内存。

## 交互与范围

- 安装、更新、修复任务切换；准备、检查、下载、下载后检查、校验、收尾、重试、暂停、无进展、正在停止与各终态。
- 浅深主题、1024×640 最小窗口、150% 文字、可展开的并行文件进度；窄浏览器适配仅用于审稿，不是新增移动端产品支持。
- 「播放流程」约 18 秒走完一次成功流程；暂停下载、停止确认、重试、关闭结果均可操作。状态菜单用于直接检查边界情况。
- 标题栏设置按钮用于预览覆盖层；模拟最小化或隐藏后，可用状态菜单模拟完成，再返回检查一次性应用内通知。
- 暂停、日志、文件读取进度、平滑速度、30 秒检测均以静态样本或模拟切换展示；本稿不能证明真实算法、并发、Avalonia 焦点和四语言布局已达标。
- 安装路径准备、卸载、自更新与游戏启动流程不在本轮重设计范围。

## 已讨论方向

默认卡片约 320×102 DIP，与右下角拆分按钮右边缘对齐，间隔 16 DIP。卡片绝对悬浮，不再压缩壁纸或扩展整个底部面板。默认只呈现当前阶段、百分比、下载速度与下载剩余时间；检查和校验使用文件计数。

阶段导航不再展示。任务路径、完成量、活动文件与日志入口放在向上展开的详情中；暂停使用卡片标题旁的图标按钮，停止在展开后保持可见，不随文件详情滚动。下方拆分按钮保留主操作和管理菜单；主按钮按任务与状态命名，点击仍可展开详情。成功时由下方主按钮提供「开始游戏」，卡片负责显示结果与关闭入口。

| 任务/状态 | 主按钮名称 |
| --- | --- |
| 安装任务下载中 | 正在下载 |
| 更新任务下载中 | 正在更新 |
| 修复任务下载中 | 正在修复 |
| 下载暂停 | 下载暂停 |
| 准备、检查、校验、收尾 | 准备安装/更新/修复、正在检查、正在校验、正在安装/更新/修复 |
| 自动重试、无进展、停止中 | 正在重试、等待进展、正在停止 |
| 失败、已停止 | 安装/更新/修复失败、安装/更新/修复已停止 |
| 成功、无需更改、待机 | 开始游戏 |

图标、悬停提示和无障碍名称与按钮状态同步。

百分比仍属于当前阶段，下载时间估算明确限定到下载。任务结果原位保留，前台可见时不重复通知；覆盖、最小化与托盘恢复沿用第一版的应用内通知演示。

沿用仓库 M3 语义、间距与字阶、明暗中性色以及现有壁纸。固定品牌蓝仅作色彩样本，不实现运行时 HCT 配色。
