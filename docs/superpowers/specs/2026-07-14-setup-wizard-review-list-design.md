# 设置向导确认页分隔列表设计

## 目标

将设置向导最后一步的确认摘要改为分隔列表，使每项标签、值和修改按钮垂直居中，并为相邻项目提供清晰、低干扰的视觉分界。

## 布局

- 保持语言、下载源、游戏安装路径和代理四项的顺序、绑定和值截断行为。
- 每项保留三列：标签、值、修改按钮。
- 每行使用一致的最小高度与垂直居中对齐；修改按钮保持右侧对齐。
- 行与行之间加入细分隔线；首行前和末行后不添加分隔线。
- 摘要容器保持既有 `info-strip` 语义与向导整体尺寸，不引入新的色块层级。

## 行为与无障碍

- 四个修改按钮继续调用既有 `GoToStepCommand` 和相同的步骤参数。
- 保持既有本地化 `AutomationProperties.Name`。
- 键盘焦点顺序与现有四个修改按钮顺序一致。

## 实现边界

- 仅修改 `Views/SetupWizardOverlay.axaml`、必要的向导专属样式及对应 UI 契约/无头测试。
- 不修改 ViewModel、设置字段、保存行为、语言资源或公共服务。
- 仅使用现有间距和颜色令牌；不引入原始颜色或间距。

## 验收

- 样式契约验证四行均使用统一行类、垂直居中，以及三个行间分隔线。
- 无头 UI 验证四个修改按钮保持自动化名称与正确步骤参数。
- 执行 `UiStyleContractTests`、向导无头测试、`test.ps1` 和 `build.ps1`。
