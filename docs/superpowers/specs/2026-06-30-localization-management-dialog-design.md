# 汉化管理对话框调整设计

## 目标

使该功能的名称准确表达“启用或停用各项汉化资源”，恢复用户指定的简体中文译文，并避免对话框尺寸随内容变化。

## 文案

- 功能名称从“资源面板”改为“汉化管理”。
- 英文和日文名称同步表达汉化资源启用状态管理。
- 恢复截图中受影响的简体中文译文：
  - “本地化”恢复为“汉化”。
  - “主线中文语音”恢复为“主线中配”。
  - “图像与视频”恢复为“图像视频”。
- 不修改本地化键名、模型标识符、API 字段或资源代码。

## 布局

- 将汉化管理对话框从最大尺寸 `720 × 592` 改为固定尺寸 `720 × 592`。
- 内容区域继续使用现有滚动容器；内容超出固定高度时在对话框内部滚动。
- 不修改其他对话框的尺寸策略。

## 验证

- 本地化测试验证三种语言中的功能名称与恢复后的简体中文译文。
- UI 样式契约测试验证汉化管理对话框使用固定宽高，且不再使用最大宽高。
- 运行项目完整验证脚本。
