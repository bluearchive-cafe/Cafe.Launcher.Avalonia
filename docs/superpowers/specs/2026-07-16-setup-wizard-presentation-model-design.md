# 设置向导展示模型与审查问题修复设计

## 目标

修复自 `v1.0.0-beta.5` 以来审查发现的设置兼容、向导引导和代码规范问题。向导的推荐、已完成摘要和路径说明统一由展示模型提供，避免在 ViewModel 与 XAML 中新增彼此独立的条件和字符串属性。

## 架构

### 步骤展示

扩展 `SetupWizardStepItem`，使其同时承载步骤标题、状态、可导航性和完成摘要。`SetupWizardViewModel` 在语言、游戏路径、下载源或代理变更时刷新摘要；XAML 仅在步骤已完成且摘要非空时呈现摘要。

摘要分别显示已选语言、游戏路径、下载源和代理。确认步骤没有摘要。完成、当前和锁定状态保留既有导航语义，并通过已有状态样式区分。

### 下载源展示

引入向导专用下载源展示模型，包含代码、显示名称、是否推荐和推荐原因。仅当界面语言为简体中文或繁体中文时，Cafe 选项标记为推荐并显示原因；其他语言不呈现推荐信息。选择值仍写入既有 `PatchUrlGroup`，不改变设置持久化格式。

### 游戏路径展示

引入向导专用路径状态展示模型，包含业务状态、标题、说明和严重度。`GamePathStatus` 继续作为可否前进的唯一业务依据；展示模型仅将既有状态转换为本地化标题与说明。UI 始终显示标题，说明在非空时显示，用于解释无效或不可访问路径的下一步。

## 兼容性与规范修复

- 将 `resourcePanelUidSource` 置于 `LauncherSettings` 的序列化属性末尾，保持既有字段顺序。
- 音频播放和清理异常通过同步诊断接口记录，不在锁或音频回调路径等待异步日志。
- 为新增公开生产类型补充 XML `summary`，并按仓库约定使用 PascalCase 局部常量。

## 本地化

所有新增用户可见文本写入 `en.json`、`ja.json`、`zh-Hans.json` 和 `zh-Hant.json`。代码只请求本地化键，不包含面向用户的硬编码文本。

## 测试与验收

先添加并观察以下测试失败，再实施最小代码：

- 设置序列化测试：既有字段顺序不变，新字段位于末尾。
- 向导 ViewModel 测试：中文 Cafe 推荐、完成步骤摘要、路径状态标题与说明。
- UI 契约测试：推荐信息、完成摘要及路径说明具有稳定绑定和自动化语义。
- 日志测试：音频异常路径不阻塞等待异步日志。

实施后运行相关单元测试、`scripts/Test-LocalizationContract.ps1`、`dev.ps1 ui`、`test.ps1` 和 `build.ps1`。不修改设置业务默认值、向导步骤顺序、下载源选择规则或安装路径有效性规则。
