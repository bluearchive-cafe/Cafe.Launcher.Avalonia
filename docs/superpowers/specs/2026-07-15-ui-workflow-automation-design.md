# UI 工作流自动化设计

## 目标

缩短 Avalonia 界面小改动从反馈到验证的周期，同时保留合并前的完整质量门禁。新增快速 UI 检查命令、本地化资源契约检查脚本和项目级 UI 修复 Skill。

## 快速 UI 检查命令

- 新增根目录 `dev.ps1`，支持 `ui` 参数。
- `./dev.ps1 ui` 仅执行 UI 相关验证：`UiStyleContractTests`、无头 UI 测试，以及与界面变更相关的现有测试筛选。
- 任一命令失败时立即返回其非零退出码；成功时返回零。
- 不执行覆盖率、Release 构建或安装器打包；这些继续由 `verify.ps1` 负责。

## 本地化资源契约检查

- 新增 `scripts/Test-LocalizationContract.ps1`，以 `Assets/Locales/en.json` 为基准检查 `ja.json`、`zh-Hans.json` 与 `zh-Hant.json`。
- 检查每种语言缺失键和多余键，并逐键比较 .NET 复合格式占位符，例如 `{0}` 与 `{1}`。
- 只读取并报告问题；不重排、格式化或修改 JSON 文件。
- 发现任一不一致时以非零退出码结束，输出语言、键和不匹配类型。

## Avalonia UI 修复 Skill

- 新增 `.agents/skills/avalonia-ui-patch/SKILL.md`，用于局部 UI 修复。
- Skill 固化最小流程：理解截图或文字反馈、定位 XAML/样式令牌与绑定、进行最小修改、增加针对性无头或样式契约测试、执行 `./dev.ps1 ui`。
- 复用现有设计令牌和本地化机制，禁止为局部修复引入原始颜色、间距、依赖或无关重构。
- 以下情况不适用：设置持久化、导航规则、外部程序集成，或跨多个产品步骤的体验变更；这些情况必须进入完整设计和实施计划流程。

## 验收

- `./dev.ps1 ui` 能运行并传播 UI 验证结果，且不调用 `coverage.ps1`、Release 构建或打包脚本。
- 本地化脚本在仓库现有四个资源文件上成功；临时制造的缺键、多键或占位符不一致都能失败并给出精确诊断。
- Skill 内容包含适用范围、操作步骤、验证命令和升级条件。
- 新增或调整的脚本遵循现有 PowerShell 错误处理与遥测禁用约定。
