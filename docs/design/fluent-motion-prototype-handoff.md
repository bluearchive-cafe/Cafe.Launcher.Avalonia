# Fluent 动效实验台交接

## 目标

建立一个与产品代码隔离的 Avalonia 动效实验台，用真实 Avalonia 渲染、语义 Token 和 Windows Fluent 曲线验证 ADR-016。实验台只回答动效手感、连续性、中断和降动效行为，不承担正式架构或生产迁移。

## 必须遵守的设计边界

- 保留产品的 M3 色彩、形状、组件和布局语义，只比较动效行为。
- 时长阶梯：83ms / 167ms / 250ms；333ms 仅供较大的连续空间变化候选使用。
- 曲线：Windows 进入减速、退出加速、点到点移动语义。
- 常规控件不缩放、不弹跳；错误不震动；不使用撒彩纸或覆盖式庆祝。
- 所有动画可中断，最新状态优先，不允许排队追赶状态。
- `Reduced` 关闭空间移动、自动轮播和大面积淡化；仅临时表面保留最多 83ms 的纯透明度过渡。

## 代表场景矩阵

1. 壳层首次整体淡入，首帧允许交互。
2. 模态遮罩与表面进入/退出，包括退出完成前保持模态交互权。
3. 设置同级分类交叉淡化，并测试快速连续选择。
4. 设置向导前进/后退方向切换与不超过 250ms 的完成确认态。
5. 轮播手动方向切换、自动交叉淡化和降动效停止自动播放。
6. 游戏操作表面在安装、控制、进度、成功、停止和失败之间转换。
7. Toast 从右侧进入、退出和多条消息堆栈重排。
8. 壁纸加载完成后的交叉淡化，以及主题 Token 同步切换。

## 实验台控制

- 每个场景可切换 `Legacy`、`Fluent`、`Reduced` 三种模式。
- 提供单次重播、快速连续触发和重置。
- 显示当前时长、曲线、位移和降级路径，但不要求复刻完整产品 UI。
- 支持 Light/Dark，至少在 100% 与 150% Windows 缩放下人工走查。

## 原型验收

- 进入方向能够解释来源或导航关系；无关系的内容不产生方向暗示。
- 动画中途收到新状态时直接接续或取消，最终状态始终正确。
- 临时表面退出期间不存在点击穿透，完成后焦点返回触发者。
- 连续容器变化不能保持流畅时，演示交叉淡化和立即切换两级降级。
- 完整与降动效模式都不以动画作为唯一状态信息。
- 用户确认整个代表场景矩阵后，才以该原型为主要视觉依据进入 `/to-spec`。

## 非目标

- 不重新设计首页布局、底栏形态、M3 组件视觉或动态配色算法。
- 不引入 WinUI 依赖，也不追求 WinUI 像素级一致。
- 不在原型阶段修改生产视图、设置架构或模态栈实现。
