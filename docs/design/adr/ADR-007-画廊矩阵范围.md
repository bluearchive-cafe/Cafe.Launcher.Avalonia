# ADR-007: 画廊状态矩阵展示范围（§9）

- 状态：**已接受**（2026-08-25，P2 决策 Round 1）
- 背景：画廊组件状态矩阵（P2 内容）需限定展示范围，避免过度构建。
- 决策：**3 组组件 × 6 态**——四型按钮（filled/outlined/text/error-filled）、卡片（含 Toast 卡）、设置行；状态 = normal/hover/pressed/disabled/focus-visible/invalid（无效态仅设置行/输入类展示）。
- 后果：矩阵同时是走查清单实物载体（spec §4）；范围外组件后续按需扩展。

- 修订（2026-09-06）：按钮组由四型扩为**五型**（+filled tonal，ADR-004 修订），矩阵行 = 5 型按钮 + 卡片 + 设置行 × 6 态；按钮行 invalid 仍以空占位表达，其余范围不变。
