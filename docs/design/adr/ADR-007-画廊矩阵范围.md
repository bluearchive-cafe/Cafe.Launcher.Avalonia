# ADR-007：画廊状态矩阵展示范围（§9）

- 状态：✅ 已接受（2026-08-25，P2 决策 Round 1）
- 日期：2026-08-25

## 背景

画廊组件状态矩阵是 P2 的内容，需要限定展示范围，避免过度构建。

## 决策

**3 组组件 × 6 态**：

- 组件：四型按钮（filled / outlined / text / error-filled）、卡片（含 Toast 卡）、设置行；
- 状态：normal / hover / pressed / disabled / focus-visible / invalid，无效态仅在设置行 / 输入类展示。

## 后果

- 矩阵同时是走查清单的实物载体（spec §4）。
- 范围外组件后续按需扩展。
