# ADR-046：卸载默认删除游戏目录，并报告整树进度

- 状态：✅ 已接受
- 日期：2026-09-30
- 来源：用户明确要求「更改卸载流程 默认删除整个游戏目录 并添加卸载进度」
- 取代：[ADR-030](ADR-030-卸载可彻底清除.md) 与 [ADR-045](ADR-045-卸载与安装的完整性口径必须说出清单外内容.md) 中的默认卸载范围、确认框和卸载日志口径；ADR-045 的安装提示和下载差异日志继续有效。

启动器清单只覆盖游戏的一部分，默认按清单卸载会留下游戏自行下载的大量资源。按用户要求，默认卸载改为删除整个游戏目录，包括清单外资源、用户放入的文件、暂存文件与安装状态，同时清理续传标记和桌面快捷方式。确认框明确显示不可恢复的删除范围、具体路径与异步测量的整目录大小，执行沿用用户确认时的安装快照。

`UninstallScope.GameDirectory` 是默认范围；未勾选的附加项只控制是否同时删除启动器受管的 `compatibility/<gameId>` 子树（`GameDirectoryAndManagedCompatibility`）。自定义 Prefix 位于两组删除目标之外时保留并说明。此决定明确覆盖之前「整目录删除不预置」的取舍。

删除前在线程池扫描所选目标，生成包含文件、链接与目录的计划。扫描阶段显示不定进度；删除阶段按已处理条目 / 总条目显示 0–95%，最后清理续传标记和快捷方式后再显示 100%。单项失败也计入已处理数，但不计入实际删除数；完成文案报告残留路径，日志记录实际删除文件数与字节数、已处理条目及残留数量。

所有目标在任何删除前通过路径守卫；树内链接只删除链接本身。执行计划重新读取属性并拒绝经过变成链接的祖先，扫描后新增内容导致目录无法移除时作为残留报告。卸载不依赖远端可用或版本状态；损坏的本地元数据允许进入整目录卸载，读取 I/O 失败仍拒绝。游戏进程家族检查在扫描结束、实际删除之前重做，缺少可用配置时由注入的游戏档案提供已知进程家族。
