# ADR-015: 对话框家族 v2 —— DialogSurface 统一框架

- 状态：**已接受**（2026-08-27，用户批准 `prototypes/dialog-toast-m3-design.html` v2 视觉稿后启动）
- 背景：
  - ADR-014 曾规定对话框族统一"头部（icon+标题+✕）→ 可滚内容 → `dialog-footer` hairline 操作带"；次日 `b02711f` 将确认框改为 M3 basic 解剖（无头带/底带），并自留"confirm-panel 圆角差异待补 ADR"欠账。
  - 样式层收敛路线（`50f1871`→`b02711f`→`aeb0ef6`）反复手工对齐后仍持续漂移：ConfirmDialog 六个永不渲染的死属性仍在被调用点传参、三种尺寸声明法并存、`overlay-dialog` 与 `confirm-panel` 定位职责重叠、ConfirmDialog 无动效而其余表面有等。
  - BoxShadow 无 TypeConverter 造成 Elevation token 定义后从未被消费，各 Setter 只能裸写字符串。
- 决策：
  - **唯一载体**：新 TemplatedControl `Controls.DialogSurface`，视觉契约集中于 `Views/Styles/DialogSurface.axaml`（单一 ControlTheme 模板 + 伪类规则）。使用方不得自带几何、色彩或阴影值。
  - **两合法形态**：`Form = Basic | Panel` 经 `:panel` 伪类切换同一骨架的解剖块——Basic 无头带/发丝线、可选裸图标（只渲染图标本体，无容器）、动作即出口；Panel 具备 56px 头带（徽章 32 圆形 tonal 容器 + 标题列 Title.Lg + 可选副标题 + ✕）、共享滚动正文、发丝底带（左辅助槽 + 右主动作组）。
  - **状态修饰**：`Status = None|Info|Warning|Danger` 映射 `:info :warning :danger` 伪类，仅重染徽章语调。警示卡（原 `dialog-alert` 规格原样收编）作为内容级插槽供两形态挂载。
  - **表面档案（组件级 token）**：`Launcher.Component.Dialog.CornerRadius`=20、`Launcher.Elevation.Shadow.Dialog`=双层阴影（经新 `Helpers.BoxShadowsExtension` 加载期解析消费）、`Badge.Size/CornerRadius`、Panel/Basic 两套 padding 家族。模态表面比页面常驻面板高半档；ADR-002（形状刻度）与 ADR-005（字阶数值）不修。
  - **关闭矩阵**：✕ 仅 Panel 头带标配，必须绑定 CloseCommand 且带本地化 AutomationName/ToolTip；Basic 确认框动作即出口；向导"跳过"保留文字按钮语义但样式出自 `dialog-action` 家族；ESC 由 ShellLifecycle 统一路由并补齐设计画廊；遮罩点击关闭明确不支持。
  - **动效**：全部对话式表面统一走 `MotionVisibility` 显隐通道（进入 Content 200ms ExponentialEaseOut + Offset.Surface 上滑淡入，退出 Fast 167ms），不为对话框新开 scale 或专属曲线通道。
  - **尺寸律**：自适应优先（MaxWidth+Stretch、内容驱动高度、超限滚动）；固定 Width/Height 必须用专属 token 且注明理由；修正 Notice 错引 `ResourcePanel.Content.MaxHeight` 的错位引用。
  - **ConfirmDialog 重生**：旧类及六个死属性删除，重生为归约成 Basic 标准用法的薄门面（类型化 Safe/Danger 文本、命令、IsDanger），"安全钮在左、主钮填充在右、默认焦点安全操作"规律类型化。
  - **显示管线不动**：bool 属性 → `SyncModal` → ModalHost 栈保持现状，DataTemplate 化留作将来独立议题；画廊入栈与 ESC 补齐随迁移批次落地。
  - **测试句式升级**：核心契约为"凡对话式表面必须是 `controls|DialogSurface`"，配合控件级行为测试（形态切换、命令装配、插槽可见性、伪类）；近期回归（如 `SettingsContent_WhenScrolledToEnd_KeepsCloseButtonInsideDialog`）在新外壳上延续生效。
- 结算：本决策**取代** ADR-014 中"对话框族统一头带+footer 定式"的表述——Basic 形态回归 M3 basic 解剖且被正式承认（不再是欠账差异）；`confirm-panel` Radius.Lg 差异账随表面档案（组件圆角 20）注销。Toast 部分维持 ADR-014 决策不变。
- 后果：迁移按 B1（确认框×8）→ B2（公告/更新/错误/资源面板 + Callout）→ B3（日志/调试/画廊入栈）→ B4（设置/向导 + 遗留类名清扫）四批推进，每批一次 Conventional Commit、测试全绿、受影响黄金基线以 `CAFE_GOLDEN_UPDATE=1` 重制后人工目检差异；契约测试逐批改写为新词汇并在批次内收敛，任何提交点仓库均处于可发布状态。
