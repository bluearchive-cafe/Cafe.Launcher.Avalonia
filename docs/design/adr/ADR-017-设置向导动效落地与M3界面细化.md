# ADR-017: 设置向导居中单列重设计与顺序换页动效落地

- 状态：**已接受**（2026-08-27；同日推翻早前"侧栏导航 + 声明式并行交叉淡化"方向，以 FluentMotionLab 实验台向导场景为权威基准重做）
- 背景：ADR-016 确立的 Fluent 动效语言已在 Toast、游戏操作表面落地；FluentMotionLab 场景 4（`ChangeWizardAsync`/`FadeSwapAsync`，B-Fluent 档截图走查通过）验证了向导换页参数与"居中单列 + 步骤进度标签"解剖。生产向导此前为 ADR-014 时代的侧栏导航形态，步骤过渡为声明式并行交叉淡化，与实验台不一致。用户裁定：表面保持模态面板，布局与动效一律以实验台为准。
- 决策：
  - **表面与解剖**：保持 `DialogSurface`（Form=Panel，`Launcher.Layout.SetupWizard.Width/Height`=920/560）与遮罩/外壳动效不变。内部删除左侧 `settings-navigation` 导航列与 `wizard-navigation` ListBox，改为实验台三段解剖——进度行（向导标题 + `StepProgress` caption + 跳过钮）、居中单列内容（`wizard-step` 面板 ×5，`Wizard.Content.MaxWidth`=520，标题 `wizard-step-title` 22px 居中，内容列随视口垂直居中）、动作行并入内容区。外壳模式（无头带）不提供模板内边距，三行块自管留白并消费 `Dialog.Panel.Body.Padding`；`DialogSurface.Footer` 不再使用，`RefreshChrome` 在 Footer/FooterLeading 全空时折叠 `PART_FooterBand`（不留空发丝带）。动作钮 = `wizard-action`：非主按钮为中性 tonal（`Content.Row` 底色 + `Text.Primary` 前景，Hover/Pressed 取 `Dialog.Close.Hover/Pressed`；SecondaryContainer 在暗色动态配色下过浅，与深色表面不协调），主按钮叠加 `primary-action` 转 filled；几何沿用 `dialog-action`，图标行经 `button-content` 承载 Material 图标。语言选择 `SetupWizard.Select.MinWidth` 200→280 对齐实验台控件宽度。
  - **步骤切换 = 顺序换页（代码后置编排）**：空间档 333ms 对半分（实验台 `ChangeWizardAsync` 用 Fluent `Profile.Normal`=333ms——实验台字段序为 Faster/Fast/Content/Normal，"Normal" 即空间档；向导按 spec 归空间连续家族，初版误用 250ms 标准档导致前载曲线下可见运动只摊约 3 帧、观感顿挫，已纠正）——旧内容以 166.5ms + `Easing.Exit`（加速）淡出（无位移、禁用命中），中点瞬时换内容并把共享 ScrollViewer 滚动复位到顶部，新内容以 166.5ms + `Easing.Enter`（减速）淡入并按方向滑入 ±14px（`Motion.Offset.StepForward/Backward`）。由 `SetupWizardOverlay` 后置代码以 CTS 取消/所有权守卫驱动（沿用操作表面模式）：最新状态优先、不排队、换面幂等（上一段动画未完成换面时也能收敛到正确可见状态）。**入场严格按实验台 `AnimateEntranceAsync` 机制**：pose（透明 0 / 位移 ±14）先经起势帧（Render 优先级排空 + 约 1 帧）渲染——目标面板首次可见引发的全量布局与文本 shaping 消化在这一不可见帧内，动画再从安静的 UI 线程起播；透明度与位移同批经 `DoubleTransition` 驱动（`Animation.RunAsync` 在非 Visual 的 Transform 上不产生动画），保证淡入与滑入逐帧同步；收尾多留 20ms 缓冲再结算（实验台 `WaitAsync` 同机制），避免最后一拍被清 transitions 截断。缺起势帧时 `Easing.Enter` 的极端前载（约 13% 时间已达 73% 进度）会把首拍时序误差放大成肉眼可见的跳变；起势帧 + 缓冲使换页墙钟约 370ms（实验台同节奏），名义令牌 333ms 不变。退场相位保持 `Animation.RunAsync`——`Easing.Exit` 后载曲线对首拍误差免疫，实测平滑。**壳层随显示步翻转**：步骤进度文本（`StepProgressText`）与动作钮状态（上一步出现、下一步↔完成切换）由 `ApplyChromeState` 在换面中点与内容面板同帧切换（实验台 swap 回调同语义）；不得绑定逻辑 `Step`——绑定会在退场前就翻到新步骤，形成"先变文本、后过渡"的两段感（初版缺陷，实测用户可感）。**步骤标题静态化**：五块 `wizard-step-title` 各自静态绑定自身资源键（`setupWizardLanguage/GamePath/DownloadSource/Proxy/Review`），完成态 `wizard-complete` 为复核面板固有静态类——共享 `StepTitle` 绑定（已删除）会在 `Step` 变化的 t=0 让全部标题（含淡出中的旧面板）同帧跳到新标题，正是"先改标题、后过渡"的残余来源；下一步的 `IsEnabled=CanGoNext` 除外，保持实时绑定（当前步校验反馈）。
  - **完成确认态**：最后一步（复核）即完成态，标准换页呈现（≤333ms）；标题 `wizard-step-title.wizard-complete` 以 Success 色标识（实验台 `WizardTitle.Foreground=Success` 语义）；动作钮切"完成"；不庆祝、不缩放。
  - **降动效**：位移 0、时长 0，幂等换面（含滚动复位）后直接定格；动效偏好运行时切换立即落定。
  - **M3 细化保留**：`wizard-option` 单选列表行（56px、整行命中、`Content.Row.Hover` 悬停层、可见选中态、`HorizontalAlignment=Stretch` 等宽拉伸保证圆圈左缘跨行对齐）、`wizard-status-row` 图标+文本状态行、`wizard-review-row` + hairline 复核列表沿用；M3 Expressive 不采用（工具型流程，按 M3 克制原则）。
  - **令牌与死代码**：删除 `SetupWizard.Navigation.Width`、`Wizard.Navigation.Padding`、`Wizard.StepNumber.MinWidth` 与 `Styles/SetupWizard.axaml` 的导航样式；新增 `Wizard.Content.MaxWidth`；删除 `StackPanel.motion-content` 的方向/退出声明式动画样式（motion-content 家族仅剩设置页六分区）；删除 `SetupWizardViewModel.Steps`/`SelectedStep`/`WizardMovesForward` 与 `SetupWizardStepItem`/`SetupWizardStepState`（方向由前后索引推导）。
- 有意偏差（记录）：①顺序换页而非 ADR-016"同级目的地纯淡化"——向导步骤有线性方向语义，实验台已验证方向滑入（Fluent 顶级导航"纯淡化"建议不适用于流程内有前后关系的换页）；②代码后置编排而非声明式样式——先出后进的顺序时序无法用 Style.Animations 表达，以操作表面的取消/守卫模式保证可中断与最终状态正确。
- 后果：`UiStyleContractTests` 向导块重写（新增 `SetupWizard_UsesConstrainedSingleColumnWorkspace`、`SetupWizard_StepsSwitchThroughSequentialFadeSwap`、`SetupWizardCompletion_StepTitleUsesSuccessColor`、`SetupWizardHeader_ShowsWizardTitleAndProgress`、`SetupWizardOverlay_UsesProgressRowAndContentActions`、`SetupWizard_ActionButtons_UseTonalAndFilledStyles`；motion-content 家族断言收敛为设置页六分区；方向/退出声明式动画断言删除）；Headless 新增 `SetupWizard_StepSwitchWithMotion_SequentialSwapSettlesOnFinalStep`（含淡入/滑入中间帧断言）、`SetupWizard_StepSwitch_ResetsScrollToTop`、`SetupWizard_OptionRows_StretchToAlignRadioCircles`，`SetupWizard_StepSwitch_LeavesOnlyFinalStepVisible` 扩展定格断言，语言用例改为断言步骤标题本地化；`SetupWizardViewModelTests` 增 `GoToStepCommand` 边界、删 Steps 摘要用例；`SetupWizardStepItemTests` 删除。**首启动效修复**：`Program.FirstLaunch` 分支只显示向导、不执行完整初始化，`IsMotionReduced` 停留在字段默认 `true`，首启向导全程降动效（步骤过渡/遮罩/表面均瞬切）——新增 `ShellLifecycle.ApplyFirstLaunchMotionPreference()`（沿 `IShellRuntime`/`MainWindowViewModel` 暴露），首启 Opened 处理器在显示向导前按默认 System 档先行应用动效偏好。**换页顿挫修复**：①时长纠正——实验台 Fluent `Profile.Normal`=333ms（字段序 Faster/Fast/Content/Normal），初版误读为 250ms 标准档，125ms 半程在前载 Enter 曲线下可见运动只摊约 3 帧，改用 `MotionTokens.SpatialDuration` 对半分；②入场补起势帧 + 透明度改 `DoubleTransition` 与位移同批驱动 + 收尾 20ms 缓冲（详见决策）；③壳层中点翻转——进度文本与动作钮解绑 `Step`、由 `ApplyChromeState` 在换面中点切换（详见决策），修复"先变文本、后过渡"两段感；④`ShowStepInstantly` 补目标面板定格（动效偏好运行时切换/重附着不再残留半程视觉），`ResetStepVisual` 先清 `Transitions` 再写终值。契约测试相应更新：进度 caption 断言改为 `x:Name="StepProgressText"` 且无 `Text` 绑定（`SetupWizardHeader_ShowsWizardTitleAndProgress`、`SetupWizardOverlay_UsesProgressRowAndContentActions`）。设置页六分区 Fast 纯淡化、外壳进出场、`Launcher.Motion.*` 令牌与配置键不变。
