# ADR-010: 中性色切换交互（Q23）

- 状态：**已接受**（2026-08-25，P2 决策 Round 2；2026-08-28 修订）
- 背景：中性策略可切换（品牌蓝调默认 / 种子跟随），交互未定。
- 决策：仅一行 ComboBox（品牌蓝调/种子跟随），**无阻断对话框**；选"种子跟随"时设置页显示一行 caption 提示"中性色将随壁纸/主题色轻微染色，tone 档位固定，对比度仍保证"。
- 后果：surface/outline 随种子漂移但 AA 安全（tone 固定）；提示文案走 4 语言 resx。
- 修订（2026-08-28）：可见实心表面从 `Dialog.Background` 单键扩展为**对话框表面族** `Dialog.Background/Header/Footer/Close.Hover/Close.Pressed` 五键——种子跟随时整套随 scheme 中性表面梯度染色（`Surface`/`SurfaceContainerLow`/`SurfaceContainerHigh`/`SurfaceContainerHighest`），品牌蓝调时五键**恒复位**为 App.axaml 声明默认值（由 `MaterialSchemeGenerator.DialogSurfaceDefaults` 承载，`UiStyleContractTests` 锁定 XAML 与表格一致），修复会话内切回品牌蓝调后对话框残留种子染色的缺陷；headless 回归测试 `NeutralStrategyHeadlessTests` 锁定切换行为。
