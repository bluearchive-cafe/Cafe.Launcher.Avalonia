# ADR-010：中性色切换交互（Q23）

- 状态：✅ 已接受（2026-08-25，P2 决策 Round 2；2026-08-28 修订）
- 日期：2026-08-25

## 背景

中性策略可切换（品牌蓝调为默认 / 种子跟随），切换交互未定。

## 决策

- 仅一行 ComboBox（品牌蓝调 / 种子跟随），**无阻断对话框**；选「种子跟随」时设置页显示一行 caption：「中性色将随壁纸 / 主题色轻微染色，tone 档位固定，对比度仍保证」。
- **2026-08-28 修订**：可见实心表面从 `Dialog.Background` 单键扩展为**对话框表面族**五键——`Dialog.Background` / `Header` / `Footer` / `Close.Hover` / `Close.Pressed`。种子跟随时整套随 scheme 中性表面梯度染色（`Surface` / `SurfaceContainerLow` / `SurfaceContainerHigh` / `SurfaceContainerHighest`）；品牌蓝调时五键**恒复位**为 `App.axaml` 声明的默认值（由 `MaterialSchemeGenerator.DialogSurfaceDefaults` 承载，`UiStyleContractTests` 锁定 XAML 与表格一致）。这修复了会话内切回品牌蓝调后对话框残留种子染色的缺陷。

## 后果

- surface / outline 随种子漂移，但 tone 档位固定，AA 仍然成立。
- 提示文案走 4 语言 resx；headless 回归测试 `NeutralStrategyHeadlessTests` 锁定切换行为。
