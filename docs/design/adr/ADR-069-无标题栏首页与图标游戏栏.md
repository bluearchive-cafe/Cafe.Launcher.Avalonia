# ADR-069：无标题栏首页与图标游戏栏

- 状态：已接受（表面材质由 [ADR-072](ADR-072-撤销玻璃子系统并回归半透明实底.md) 更新为半透明实底；布局与尺寸不变）
- 日期：2026-11-19
- 修订 [ADR-067](ADR-067-FluentAvalonia共享控件模板.md) 的主窗口标题栏条款、[ADR-057](ADR-057-统一操作面板与任务对话框.md) 的底栏布局与任务卡宽度，并接续 [ADR-063](ADR-063-全应用统一Fluent2视觉.md) 的 Fluent 2 表面规则。

## 背景

首批首页重构的设计稿经过评审后确定：顶部不再保留独立标题栏底板，游戏字标成为
内容区的主标题；游戏库收窄为纯图标轨道；主操作浮在右下角，状态信息归标题下方。
目标是在保留现有功能分区、安装准入和任务语义的前提下，改善壁纸画面的完整性与
首页操作路径。

## 决策

- **标题栏**：`FAAppWindow` 启用 `TitleBar.ExtendsContentIntoTitleBar`，标题栏高度
  为 48 DIP，活动/非活动背景透明。窗口按钮仍由 FluentAvalonia 与平台绘制并贴在
  窗口右上角，应用不重复实现最小化、最大化、关闭。顶部工具行为无底板、无边框的
  48 DIP 行，右侧为窗口按钮预留 138 DIP。页头容器声明
  `WindowDecorationProperties.ElementRole="TitleBar"`，其空白处由系统按标题栏拖动、
  双击最大化和右键系统菜单处理；页头内的「游戏设置」「资源面板」按钮标记 `User`，
  点击与键盘焦点不被拖动判定吞掉。
- **游戏库**：左侧栏宽 64 DIP、贯穿窗口全高，使用 Fluent 单选列表承载 44 DIP
  图标按钮。游戏名称、区服和任务进度通过悬停与键盘焦点工具提示显示；后台任务
  与失败使用 16 DIP 角标，不再在栏内铺开文字任务按钮。诊断与启动器设置保留为
  栏底图标按钮。
- **标题与状态**：官方字标或品牌文字移到内容区左上，作为游戏标题的主元素
  （官方字标高 80 DIP）。状态行位于标题下方，按「状态面板」设置显示或隐藏，
  继续以游戏会话状态为首项；它不再属于主操作表面。
- **资讯**：资讯区位于标题下方的左侧身份区，宽 476 DIP，底边与主操作底边
  对齐；横幅高 220 DIP，与公告面板无缝拼接。官网与社交链接保留在滚动区末尾。
- **主操作**：分体按钮浮在窗口右下角，距右/下 12 DIP，最小宽 180 DIP、高 48 DIP；
  菜单继续向上展开。任务卡固定宽 382 DIP，右缘与按钮对齐，位于按钮上方 16 DIP，
  不参与布局测量，也不压缩壁纸和资讯。资讯与主操作以水平分离保证不互相遮挡。
- **表面**：新增 `Launcher.Color.Glass.Rail.Background`（约 92%）、
  `Launcher.Color.Glass.Strong.Background`（浅色约 79%、深色约 82%）与
  `Launcher.Color.Glass.Edge`，分别用于图标栏和强档内容表面（资讯面板、任务卡、
  管理菜单、首页工具提示）。Avalonia 不提供同窗口兄弟内容的背景模糊，因此以
  半透明底色、发丝描边和阴影实现等价视觉，不伪造模糊；主题色切换沿用
  `MaterialSchemeGenerator` 的玻璃表面派生规则。

## 结果

- 首页不再有横跨底部的操作栏，状态信息归标题下方；底栏三态布局的
  `OperationSurface` 高度形变不再承载产品语义，保留的入场/状态动效不得依赖
  底栏宽度或高度。
- 导航名称不再常驻显示。键盘用户依赖列表项的自动化名称与焦点工具提示；
  后台任务通过角标提示，进入所属游戏后由主操作与任务卡继续承接。
- 顶部工具行右侧的 138 DIP 是平台窗口按钮的保留区，工具行自身不再绘制
  窗口按钮，也不声明系统标题栏颜色以外的自绘按钮。
- 任务卡宽度从 320 DIP 调整为 382 DIP，截图基线、任务卡标题槽和浮动位置需要
  同步回归。

## 回归

- 无头测试覆盖：标题栏扩展与 48 DIP 工具行、页头空白解析为 `TitleBar` 且页头操作
  解析为 `User`、64 DIP 图标栏和工具提示、后台任务/失败角标、标题与状态行、资讯
  底边与主操作底边对齐、任务卡右缘与按钮右缘对齐、16 DIP 间距，以及强档玻璃
  token 随中性色策略刷新。
- 黄金基线更新 `shell-default`、`floating-task-*`、`launch-split-button*`、
  `launch-split-menu`、`progress-panel`、`session-running-zh` 及全部含首页背景的
  覆盖层截图。
