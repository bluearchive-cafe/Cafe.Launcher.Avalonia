# ADR-008: 组件批次 A→B→C 映射（Q21）

- 状态：**已接受**（2026-08-25，P2 决策 Round 2）
- 背景：Q21 定"P2 组件 = A→B→C"，需落地细目。
- 决策：
  - **A 批**：共享模板参数化 + 四型按钮落地（全部现有按钮类：主操作/扁平/文字/危险/图标/关闭/页签内按钮统一规格与模板）；
  - **B 批**：现存组件对齐（设置行、卡片、社交 chip、页签、进度条、Toast 卡——形状/状态层/字阶角色键消费）；
  - **C 批**：按需新组件（Select 等 ControlTheme + 新命名）+ 画廊状态矩阵（ADR-007 3×6）+ 走查清单。
- 后果：每批结束各自门禁（契约/基线/对比度），诊断/日志例外维持（Q3/Q21）。
