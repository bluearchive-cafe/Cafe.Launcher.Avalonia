# ADR-072：撤销玻璃子系统，主壳表面回归半透明实底

- 状态：✅ 已接受
- 日期：2026-11-21
- 取代：[ADR-071](ADR-071-主壳玻璃表面采用窗口内采样模糊.md)
- 关联：不改动 [ADR-069](ADR-069-无标题栏首页与图标游戏栏.md) 的首页布局与表面层级，不改动 [ADR-070](ADR-070-对话框设置与通知统一为实心Fluent表面.md) 的对话框/设置/通知实心决定。

## 背景

[ADR-071](ADR-071-主壳玻璃表面采用窗口内采样模糊.md) 为主壳引入了窗口内采样模糊：`GlassSurface` 在玻璃可用时插入 `Fluid.Avalonia.Acrylic.AcrylicSurface`，不可用时回退到 `Launcher.Color.Glass.*` 半透明实底；视频壁纸还要额外维护一条「原生 GL 表面之下铺低频替身」的采样链。

该方案带来了持续捕获成本、独立的第三方依赖、能力探测与降级分支，以及视频壁纸替身这一整套只为模糊服务的旁路。维护者决定不再保留这条渲染链，主壳表面回到引入玻璃之前已经验证的半透明实底外观。

## 决策

1. **移除玻璃子系统**。删除 `GlassSurface`、`GlassSurfaceSupport` 及其样式与 `StyleInclude`，删除宿主对 `CAFE_DISABLE_GLASS` 的接线；移除 `Fluid.Avalonia.Acrylic` 的工程引用、中央版本登记、第三方许可声明与工具链表行。视觉与主题不再依赖 GPU 捕获。
2. **表面 token 保持稳定**。`Launcher.Color.Glass.*` 与 `Launcher.Color.Danger.OnGlass` / `Info.OnGlass` 是半透明实底表面及其语义前景的稳定键名，数值与亮暗派生规则不变。左侧图标栏、资讯整组与浮动任务卡由宿主 `Border` 直接绘制底色与发丝描边，不再叠加采样层。
3. **移除视频替身**。删除 `VideoPosterSurrogate`、`VideoBackgroundControl` 的 GL 读回/降采样、`SurrogateFrameReady` 事件及相关测试。视频壁纸只负责播放；静态壁纸在首帧后被不透明视频遮挡并隐藏。
4. **同步契约与文档**。设计规范、PROJECT_CONVENTIONS、THIRD-PARTY-NOTICES、第三方测试与 `cafe-docs` 中的用户说明按「半透明实底表面」重写；相关 headless 与样式契约测试改为锁定 `Border` 上的 `Glass.*` 资源。
5. **研究证据保留**。`prototypes/GlassMaterialLab/` 保留为 2026-11-20 的历史研究记录，其中的候选对比、视频模拟与帧成本数据不再描述生产实现；若再次引入窗口内模糊，需要新的 ADR 重新评估，不能沿用已删除的接口名。

## 后果

- 主壳没有玻璃模糊、没有窗口内捕获、没有视频替身采样，也没有软件渲染/远程会话/高对比下的材质降级分支；这些环境与 GPU 环境看到同一套半透明表面。
- 少一个第三方依赖及其许可披露；视频壁纸路径只保留播放与静态壁纸隐藏逻辑。
- 极端明暗壁纸下的对比度仍由 `Launcher.Color.Glass.*` 的不透明度下限与 `DesignTokenContrastTests` 承担；更换壁纸观感时不透明度不随内容变化。
- 半透明表面仍会让壁纸透出，但这是 token 的既定视觉，不再承诺「真实背景模糊」。若产品或设计需要模糊，需以新决策重新引入，并重新评估捕获成本、平台能力与回退契约。
