# ADR-013: 设置页重设计方向（Q12 表现级重排）

- 状态：**已接受**（2026-08-25，P2 决策 Round 3）
- 背景：Q12 允许表现级布局自由；Q18 已仲裁 M3 贴边底栏；设置页需确定 P3 表面级重排方向。
- 决策：
  - **变体 B：纯列表 + hairline 分隔线**（含 Q24 三个新设置项与外观点全部示例；组间空档分隔，行间 1px `OutlineVariant` hairline；不引入卡片分组）；
  - **导航选中态**：`SecondaryContainer` 底 + `OnSecondaryContainer` 字 + 3px Primary 指示条（替换现行 FlatPressed 底色），hover/pressed 用 `StateLayer` 8/12/16%；
  - 覆盖层表面：`Radius.Lg`(16) + `Elevation.Shadow.Lg` + `Dialog.Background`；控件统一 `Field` 形态（`Field.Background`/`Field.Border`/`Radius.Md`/2px 聚焦环）。
- 后果：P2 仍只做规格统一（ADR-006 不变），本方向作为 P3 表面执行蓝图；双主题原型（`prototype/settings-page`）评审后折入 spec §5。
