# ADR-013: 设置页重设计方向（Q12 表现级重排）

- 状态：**已接受**（2026-08-25，P2 决策 Round 3；M3 审核 + 评审订正后定稿）
- 背景：Q12 允许表现级布局自由；Q18 已仲裁 M3 贴边底栏；设置页需确定 P3 表面级重排方向。
- 决策：
  - **变体 B：纯列表 + hairline 分隔线**（含 Q24 三个新设置项与外观点全部示例；组间空档分隔，行间 1px inset hairline；不引入卡片分组）；
  - **导航选中态**：`SecondaryContainer` 底 + `OnSecondaryContainer` 字 + leading icon + 标签（**无指示条**，评审定案）；hover/pressed 用 `StateLayer` 8/12/16%；
  - **标题栏拆分**：取消通栏标题栏；「设置」标题并入导航列顶部 header，关闭按钮（✕）并入内容区标题行右端；两列自顶到底，底部操作带（取消/保存）不变；
  - 覆盖层表面：`Radius.Lg`(16) + `Elevation.Shadow.Lg` + `Dialog.Background`；控件统一 `Field` 形态（`Field.Background`/`Field.Border`/`Radius.Md`/2px 聚焦环）。
- 后果：P2 仍只做规格统一（ADR-006 不变），本方向作为 P3 表面执行蓝图。

## M3 设计审核修正（2026-08-25，material-design 技能审核）

1. **Field.Border 对比度**：浅色 `#B8CADB`（≈1.8:1）→ `#7E93AC`（≈3.15:1）；深色 `#40516A`（≈2.13:1）→ `#5B7190`（≈3.44:1）——控件边界 ≥3:1（WCAG 1.4.11）。**生产 token 值需同步**（P2/P3 调色清单）。
2. **行分隔线改为 inset**：与文本左缘对齐（左缩进 16px），符合 M3 组内逐条分隔规范；生产以 `Color.Card.Border` 为 hairline 色（不新增 outlineVariant token）。
3. **导航抽屉项补 leading icon**（M3 抽屉解剖 = 图标 + 标签 + 激活指示；Material Symbols：settings/sports_esports/download/palette/tune/info）。
4. 记录性偏差：触控目标 36px（桌面指针语境，ADR-003 保持现值）；"动画" Switch 即时生效符合 M3。
5. **评审定案（2026-08-25）：移除导航指示条（3px Primary 竖条）**——激活态仅由 `SecondaryContainer` 填充 + 图标/文字强调表达（M3 Navigation Drawer 标准激活方式之一）；原型已同步。若后续需要更强激活信号，可恢复指示条或加文字字重强调，不阻塞定稿。
6. **评审定案（2026-08-25）：拆分标题栏**——取消通栏标题栏；「设置」标题并入导航列（顶部 header），关闭按钮（✕）并入内容区标题行右端（`content-header` 行）。结构 = 两列自顶到底（导航列含标题头；内容区含分类标题 + 关闭按钮），底部操作带不变。

> 原型（primary source）：分支 `prototype/settings-page`，`prototypes/settings-page/index.html`（双主题、纯 CSS）。
