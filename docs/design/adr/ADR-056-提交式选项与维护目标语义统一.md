# ADR-056: 提交式选项与维护目标语义统一

- 状态：**已接受**（2026-11-07，用户要求落实界面审查建议，优先修复语义并同步规范与文档）
- 日期：2026-11-07
- 取代范围：ADR-041 的资源条目 Switch 选择；ADR-018 的关于页信息顺序。其余骨架、来源单选与服务端保存机制不变。

## 背景

设置和资源偏好均有明确的保存事务。Switch 的外观暗示当前已应用状态，但原实现只修改草稿；资源面板关闭、刷新或切换 UID 时还可能丢失修改。游戏路径编辑显示草稿，旁边维护命令却使用已应用安装快照，容易混淆操作目标。保留批量保存可以继续支持取消、失败后重试和一次提交多项资源偏好；逐项即时写入会改变这些既有契约。

## 决策

1. 保留事务式保存。设置中的布尔选项、资源偏好独立多选使用 `CheckBox.setting-checkbox`；外观即时预览是可撤销的草稿预览，不等同于保存。设置页显示保存说明，外观页补充预览与取消的说明。
2. 资源面板显示未保存状态。关闭（含 ESC）、刷新、切换 UID 来源或提交另一 UID 前，若将覆盖现有草稿，先询问是否放弃；取消保留全部草稿与原来源，确认后只执行原请求，不代替用户保存。UID 来源与手动 UID 仍在各自操作成功时立即保存，资源选择仍由「保存设置」提交。保存或加载期间不接受上述离开操作，资源选择不可编辑。
3. 游戏设置拆分路径草稿与当前安装维护。维护区展示命令实际使用的安装快照目录；路径有未保存修改时禁用目录、修复和卸载入口，保存或恢复原路径后重新可用。命令的状态准入与卸载路径复核保留。
4. 色板使用互斥 RadioButton，保留当前种子与索引同步，同时暴露选择语义、方向键/Home/End 与辅助技术操作。
5. 所有设置行统一普通字重，组标题使用强调字重与主文本色，说明继续使用次要文本色；音量滑块的原生输入模型保留，其轨道、滑块、状态与焦点映射到现有 Launcher 角色。
6. 关于页顺序为文本身份卡与常用动作、帮助/仓库/反馈入口、默认折叠的五项构建与运行信息、法律信息。首页状态面板保持原有状态信息行。向导保持同一固定动作区和滚动模型，高度上限从 560 收至 480 DIP，减少稀疏步骤留白。

## 后果

本次不改变 settings.json 字段、服务端资源配置协议、程序集或跨功能所有权。新增放弃确认沿用既有确认组件、模态栈和焦点恢复机制。既有 ADR 保留历史背景，现行规则由设计规范与领域契约维护；新交互附回归与黄金图。

## 修订（2026-11-07：外观页结构级对齐）

外观页延续本 ADR 的提交式草稿语义，只调整选择控制的形状与配色呈现：

1. 主题、背景来源、壁纸适配与中性色策略这四组 2–3 项短标签互斥值时使用分段按钮（`RadioButton.segment-option` + `Segmented.axaml` 共享模板）；长标签或 ≥4 项的动态效果、取色算法、配色变体、主题色来源仍用下拉菜单。分段与草稿的接缝由 `SegmentOptionConverter` 承担，未选中段的反选不写回来源。
2. 主题色来源下拉的每一项前置圆点，预演该来源当前解析出的主色；触发器与菜单共用同一模板，不再于行内单放一枚与选项无关的色块。
3. 自定义背景的清除动作收成图标按钮（保留 tooltip 与辅助名称），使它与两个带文字的选择动作区分视觉重量。
4. 同一规则扩展到其余设置页：常规页的关闭行为、状态面板、更新通道（各 2 项短标签）与下载与网络页的下载源（官方/Cafe）改用分段按钮；游戏启动后行为、代理、下载限速、日志级别与游戏运行器因标签较长或选项 ≥4 项继续用下拉。
