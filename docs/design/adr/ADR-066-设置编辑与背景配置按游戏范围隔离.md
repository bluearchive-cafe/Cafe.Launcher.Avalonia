# ADR-066：设置编辑与背景配置按游戏范围隔离

- 状态：已接受（2026-11-16）
- 日期：2026-11-16
- 相关：[ADR-024](ADR-024-已保存设置唯一写入方.md)、[ADR-052](ADR-052-已保存设置的派生效果只有单一归属.md)、[ADR-056](ADR-056-提交式选项与维护目标语义统一.md)、[ADR-065](ADR-065-单窗口多游戏管理.md)
- 行为契约：[CONTEXT.md「多游戏管理」](../../../CONTEXT.md#多游戏管理)、[「设置与操作」](../../../CONTEXT.md#设置与操作)
- 视觉规格：[设计规范 §4.2](../design-system-spec.md#42-设置页)

## 背景

多游戏身份与上下文落地后，设置仍混在同一浮层：全局偏好与游戏字段共享导航、完整草稿一次提交；背景只有一套全局配置，而每款游戏需要自己的内置图、远程壁纸与专属媒体。用户确认的方案是启动器设置与固定游戏设置分开呈现，同时保留草稿、即时预览与统一保存的既有体验。

## 决策

1. **两个对话框、一次编辑会话**：启动器设置为常规、外观、默认背景、下载与网络、高级、关于；游戏设置为安装与维护、启动与运行、下载与资源、游戏背景。两者都是主窗口内的模态对话框，同一时间只持有一个设置编辑会话，游戏设置固定为打开时的目标游戏。
2. **全局与游戏字段**：语言、关闭行为、窗口记忆、状态面板、远程内容、启动器更新偏好、主题与配色、动效、代理、HTTP/2 与限速全局共享；安装目录、下载源、启动校验、运行环境、启动后行为、适用的汉化 UID 与背景专属覆盖按游戏保存。下载源属于游戏设置：蔚蓝档案提供官方与 Cafe，星塔旅人只提供官方；Cafe 资源入口只在蔚蓝档案出现。
3. **范围化保存**：保存只提交当前对话框明确范围的修改，经唯一写入方（ADR-024）合并到最新已保存基底，不用完整旧草稿覆盖其他分区。全局保存不写游戏条目，游戏保存不写全局字段；切换条目或切换对话框范围前先保存或放弃草稿。
4. **背景默认加整组覆盖**：全局「默认背景」定义来源、适配、填充、视频音量与静音等默认规则；游戏「游戏背景」以 `UseBackgroundOverride` 整组覆盖，关闭时继承全局默认。自定义图片、视频与文件夹只在专属覆盖中提供；关闭覆盖保留已选值，再开启可恢复。主题与配色策略仍全局共享，壁纸取色跟随当前有效背景。
5. **失败回退**：当前游戏的背景加载失败时先使用该游戏内置图，内置图也不可用时才使用共享通用背景；回退不清除原配置、不自动保存，原因与恢复入口保持可见。
6. **旧配置迁移**：旧版全局背景与自定义媒体读入各游戏条目的专属值，共用原文件路径，但覆盖开关保持关闭，因此迁移后的外观仍由全局默认规则呈现，两份值不会同时成为真值。迁移前保留 `settings.pre-multigame.json`（无版本文档）或 `settings.pre-backgrounds.json`（上一版带游戏背景的文档）备份。
7. **预览与忙碌**：外观更改即时预览；预览把设置浮层暂时收起时仍持有模态交互权，Esc 或「返回设置」回到原分类与焦点，结束时恢复该游戏的有效背景。文件任务进行期间，所属游戏的目录、下载源、运行环境等操作配置锁定；背景专属覆盖、其他游戏与全局偏好仍可保存，暂停不解除锁定。

## 取舍与后果

- 相较在一个导航列表中混排并加作用域标签，独立对话框让目标游戏与保存范围直接可见；代价是入口、分组、草稿提交与导航状态需要一起改造。
- 相较逐项立即保存，保留草稿预览、统一保存与放弃恢复；代价是必须处理预览取消、保存收敛、关闭确认与范围同步。
- 相较完全全局背景或逐字段继承，整组覆盖更容易说明「跟随默认／使用专属」；代价是新增背景分区、版本迁移和一条按游戏取有效背景的解析路径。
- 旧全局自定义媒体迁移后覆盖关闭：外观连续、行为可解释，但用户若需要专属媒体需主动开启覆盖并重新确认来源；这与「迁移即启用专属」相比少一次隐式配置变化。
- 继续保留单一设置文档、唯一写入方、提交租约与 Core/UI 分层；背景图片与图标属于 UI 资源层，不进入 Core 模型。

## 验收

- 单元契约：`SettingsScopeTests`、`SettingsWriteOwnershipTests`、`SettingsMigrationTests`（旧单游戏与旧背景版本）、`SettingsBackgroundMigrationTests`、`GameRuntimeSettingsUiTests`、`SavedSettingsWriterTests`。
- 无头回归：两个设置对话框的入口与目标游戏标题、分类切换滚动复位、范围化保存、文件任务期间的锁定、游戏背景覆盖的预览与回退、四语言与文字放大下的底栏布局。
- 背景专属覆盖、游戏切换与保存失败重试由黄金基线与交互回归覆盖；`pwsh ./verify.ps1` 为合并门槛。
