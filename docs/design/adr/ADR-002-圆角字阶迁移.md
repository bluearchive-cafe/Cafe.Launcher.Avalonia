# ADR-002：圆角字阶一次性迁移（§3.6）

- 状态：✅ 已接受（2026-08-25，P2 决策 Round 1）
- 日期：2026-08-25

## 背景

现状 Radius 为 Sm=4 / Md=6 / Lg=8，目标字阶为 Xs=4 / Sm=8 / Md=12 / Lg=16。P1 只保留现值，迁移尚未发生。

## 决策

**一次性按目标字阶重标**：`Launcher.Radius.Xs`=4、`Sm`=8、`Md`=12、`Lg`=16，全部消费方同步迁移。before/after 视觉迁移记录入 spec §8；黄金基线重生成；`DesignTokens_NewFamilies_...` 等目标刻度断言同步。

## 后果

- 一次性视觉漂移（观感整体更圆润），由黄金基线与迁移记录把关。
- Keys / 控件 / 卡片 / 对话框统一到同一字阶。
