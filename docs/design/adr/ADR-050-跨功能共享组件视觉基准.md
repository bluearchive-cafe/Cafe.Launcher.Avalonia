# ADR-050：跨功能共享组件视觉基准

- 状态：✅ 已接受（2026-11-01 用户确认组件视觉草案并授权实施）
- 日期：2026-11-01
- 替代范围：ADR-004 的按钮尺寸与次要操作外观、ADR-015 的 20 DIP 外圆角、ADR-017 的向导专属动作外观、ADR-040 的确认框专属按钮轮廓；其操作顺序、默认按钮、模态与键盘行为继续有效。ADR-020 的独立资源边界保留。

各功能已有共享模板，但确认框、设置、向导与 Toast 又分别覆盖按钮的填充、圆角、字号和禁用态。同一角色在不同表面呈现不同外观，局部修复也容易互相覆盖。用户选择统一组件视觉，主界面布局与业务流程保持现状。

采用 `Launcher.Component.Button.Theme` 作为标准操作按钮的共同几何和中性外观落点，继续使用 `LauncherBorderButtonTemplate` 与既有语义类。主操作和危险操作只选择角色色；确认框不再另设一套按钮外观，向导沿用同一主题。标准按钮与字段为 40 DIP、14 DIP 正文、8 DIP 圆角；紧凑操作为 36 DIP，主界面任务操作保留 48/58 DIP。高度使用最小值，长文案和文字放大时自然增长。对话框统一为 16 DIP 外圆角，Basic 与 Panel 的内容结构和关闭语义保留。

次要操作使用不透明的 `Button.Secondary.Background/Hover/Pressed` 中性表面，悬停和按下从中性前景预混 8%/16% 状态层。动态色与两种中性色策略继续生效，每次应用都重建三态；旧 `Dialog.Action.Background` 与新底色同步，避免策略切换留下残余。字段共用 8 DIP 圆角和相同的标准高度，取色器的原生 `DropDownButton` 触发器也使用共享主题。

按钮常驻预留 2 DIP 透明焦点描边，键盘取焦只改颜色。中性操作使用对比度至少 3:1 的 `FocusRing`，实心主操作与危险操作分别使用 `OnPrimary`、`OnError`，禁用不改变描边厚度。崩溃窗口用独立 `Crash.*` 令牌和模板映射同一几何与角色规则，隔离报告模式仍不依赖主应用资源。

保留已有类名和命令接线；画廊的 `outlined` 历史类名保留，显示名称改为“次要按钮”。验收使用跨场景无头渲染与焦点几何、动态方案对比度、现有功能测试和黄金截图；不以逐页复制样式或新增 UI 框架实现统一。

## 2026-11-07 设置下拉修订

用户确认 A 方案的真实控件样张，并授权推广到其余设置下拉及修复选中底色过淡。
设置分区以 `settings-section` 限定共享下拉主题：页面底色、中性轮廓、独立活动描边、
选中 accent 浅底和前置勾选槽；主题色来源保留原色点。通用命令菜单和其他选择框的
几何及选择语义保持原决策，具体视觉值与验证范围见[设计规范 §3.4](../design-system-spec.md#34-下拉选择与菜单2026-11-01-增补)。

底色过淡来自画刷原位更新只复制颜色、保留旧透明度。改为同步生成画刷的颜色和透明度，
保留实例身份，使生成 alpha 只应用一次；受影响的分段按钮、浅底、边界和焦点通过截图复核。

## 2026-11-11 向导动作带宽度例外

[ADR-059](ADR-059-设置向导统一舞台与双栏解剖.md) 将向导动作带收为两枚动作，并为二者设置 100 DIP 最小宽度，使短文案不被拉长，现有四语文案下上一步、下一步保持同宽；该值贴近中文动作的自然宽度（约 98）。该值只覆盖动作带的布局宽度；按钮主题、圆角、字号、焦点描边与角色色仍由本决策的共享组件决定。跨功能无头几何断言随即将向导动作的期望宽度记为 100，其余标准动作继续为 80，避免把两枚动作的等宽需求误读为新的外观分支。
