# ADR-067 FluentAvalonia 共享控件模板

- 状态：已接受
- 日期：2026-11-17
- 修订（2026-11-17）：主窗口采用 `FAAppWindow` 的默认标题栏。关闭策略继续由窗口关闭事件分派。以下自绘标题栏方案保留为历史记录。现行规格见[设计规范 §4.1](../design-system-spec.md#41-主窗口标题栏与任务表面)。
- 修订（2026-11-19）：主窗口改为 `TitleBar.ExtendsContentIntoTitleBar` 的 48 DIP 扩展区，窗口按钮仍由 FluentAvalonia/平台绘制并贴右上角；默认标题栏底板与产品名不再显示。标题栏、游戏栏和浮动主操作由 [ADR-069](ADR-069-无标题栏首页与图标游戏栏.md) 定义。
- 替代范围：延续 [ADR-063](ADR-063-全应用统一Fluent2视觉.md) 的全局主题，替换剩余共享控件中的重复模板；修订 [ADR-020](ADR-020-崩溃窗口独立Fluent设计系统.md) 的主题底座和 [ADR-057](ADR-057-统一操作面板与任务对话框.md) 的分体按钮模板实现。

## 决策

- 通用按钮、超链接、设置展开器、向导单选、资讯标签项及游戏分体按钮继承 FluentAvalonia 模板。启动器仅通过样式适配角色、尺寸和动态画刷。管理菜单与标题栏右键菜单使用 `FAMenuFlyout`，淘汰为标题栏手写的 `ContextMenu` 模板。
- 标题栏的最小化和关闭使用 `FluentDrawnCaptionButton`，保留本地化名称、键盘焦点、壁纸 scrim、版本徽标和原有关闭命令。窗口继续使用 Avalonia `Window` 与 FluentAvalonia 的窗口主题；`FAAppWindow` 会在 Windows 构造时接管原生句柄和系统菜单，也不提供启动器的关闭到托盘及覆盖层规则。保留明确的拖动区和触摸主指针判定。
- 崩溃报告进程也加载 `FluentAvaloniaTheme`。仍仅以 `Crash.*` 定义本地颜色和几何，不引用主应用令牌、动态配色或服务。
- `DialogSurface`、Toast、任务卡、横向滚动的资讯标签容器、特殊选择行和色块等继续承担启动器特有的布局和交互。它们组合共享控件，保留现有模态焦点、文字缩放和选择语义。

## 验证

覆盖标题栏命令和右键菜单、分体按钮两区与键盘操作、向导单选状态、资讯标签指示器、明暗主题和黄金截图。关闭到托盘、卸载执行时的关闭限制与游戏命令继续走已有策略。
