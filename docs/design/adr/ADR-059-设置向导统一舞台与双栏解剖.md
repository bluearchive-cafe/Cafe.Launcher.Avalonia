# ADR-059: 设置向导统一舞台与双栏解剖

- 状态：已接受（2026-11-11）

设置向导的六步长期各自演化：语言/路径/下载源/代理沿用居中单列，协议步骤在 ADR-058 修订里改成阅读器 + 同意栏双卡。用户裁定六页必须共用一套结构，差异只允许落在右侧面板；同时移除对话框顶部图标、移除协议复选框下方的提示，并统一上一步/下一步的按钮宽度。本决策以 `prototypes/setup-wizard-redesign/` 的可交互样张落地统一舞台，替代 ADR-017 的居中单列与 ADR-058 修订中的双卡协议解剖。

## 决策

- **表面**：保持 `DialogSurface`（Form=Panel，`Launcher.Layout.SetupWizard.Width/Height`=920×480）与遮罩/外壳动效不变；外壳模式无标题，表面对外语义复用「Setup Wizard」本地化键。
- **五段表面**：全幅头部 → 发丝线 → 正文滚动舞台 → 发丝线 → 全幅动作带。头部与动作带贴表面边缘，留白只由样式消费 token（`Header.Padding`、`Footer.Height`、`Footer.Padding`），视图不自带 Padding。
- **头部**：向导标题 + 本地化步骤计数（`setupWizardStepProgress`，「第 N 步，共 6 步」）+ 跳过钮 + 六段进度轨。计数与到达段由 `ApplyChromeState` 在换面中点翻转，不绑定 `Step`；单步的协议更新模式折叠整条进度轨并显示「第 1 步，共 1 步」。
- **正文舞台**：860 固定舞台 = 300 左引导 + 32 舞台间距 + 528 右面板。六步结构一致——左引导为 56 圆形语义图标 + 步骤标题 + 说明；右面板为 Card 表面（内边距 20），内容随步骤变化（语言选择、协议阅读器、路径输入与状态行、单选选项行、复核摘要行）。语言与路径字段在控件上方标注本地化字段名（`setupWizardLanguageField`、`setupWizardGamePathLocation`），路径字段补充重新检查提示。复核行的编辑入口为 Pencil 图标 + 「修改」文本。步骤纵向拉伸铺满视口，正文留白改由右面板的 `Body.Margin` 承担。
- **协议步骤**：与其余五步同构。左引导追加版次胶囊与语言声明；右面板为 `AgreementScrollViewer`（唯一滚动区）加固定底栏同意项。步骤绑定 `ScrollViewer` 视口高度，使文档在有界高度内滚动；复选框下方的滚动提示从版面移除，仅保留为 `AutomationProperties.HelpText`；勾选门禁仍由滚动到底驱动。
- **动作带**：上一步与下一步/完成同为 `wizard-action`，`MinWidth`=100（大于共享 80 DIP，贴近中文动作的自然宽度约 98；两枚动作共用同一下限，短文案不被拉长，现有四语文案下二者同宽），下一步/完成叠加 `primary-action`。上一步在左，主操作在右。这是表面级布局例外：按钮的角色外观（共享主题、圆角、字号、描边、语义色）仍由 [ADR-050](ADR-050-跨功能共享组件视觉基准.md) 决定。
- **步骤切换**：沿用 ADR-017 的顺序换页（333ms 对半分、中点换内容与滚动复位、Enter/Exit 曲线、起势帧、±14px 方向滑入、壳层中点翻转）与后置代码的可中断所有权守卫；仅布局与壳层解剖变更。
- **令牌**：新增舞台骨架 `Wizard.Stage.Width`、`Wizard.Context.Width`、`Wizard.Context.Icon.Size`、`Wizard.Header.Padding`、`Wizard.Body.Margin`、`Wizard.Footer.Height`、`Wizard.Footer.Padding`、`Wizard.Progress.Height`、`Wizard.Action.MinWidth`，以及面板内部度量 `Wizard.Agreement.Version.Padding`、`Wizard.Agreement.Consent.Padding`、`Wizard.Divider.Height`、`Wizard.Summary.Row.MinHeight`、`Wizard.Summary.IconChip.Size`、`Wizard.Option.MinHeight`、`Wizard.Option.Padding`、`Wizard.Option.Radio.Size`、`Wizard.Option.Radio.Dot.Size`、`Wizard.Option.Radio.BorderThickness`。删除 `Wizard.Content.MaxWidth`、`Wizard.Agreement.MaxHeight`、`Wizard.HeroBadge.Size`。布局间距一律取 `Launcher.Spacing` 标度（舞台间距取新增的 `Spacing.Xxxl`=32，进度轨间距 8），面板内边距取 `Spacing.Thickness.Xl`；组件令牌不得进入 `Spacing`/`Padding` 属性。样张复刻的组件内部内边距是显式例外，以组件令牌固定：头部 `24,16,24,14`、选项行 `14,13`、版次胶囊 `8,2`（沿用标题栏版本徽标的 8×2 度量）。

## 未采用

- 六步各留一套解剖、只统一配色：用户明确要求结构一致、仅右面板不同；分支解剖会继续累积样式契约与无头断言。
- 协议步骤继续双卡：在 920×480 下与其余五步的视觉节奏脱节，且双套卡片样式只能服务单一步骤。
- 用 `Margin` 直接拼出舞台间距或进度轨间距：绕过间距标度契约，且不便随字号/主题统一调整；新差距应并入 `Launcher.Spacing` 标度（本次即新增 32 档）后以 `ColumnSpacing` 消费。

## 后果

- `SetupWizardOverlay.axaml` 重写为五段表面 + 六步双栏；`SetupWizardOverlay.axaml.cs` 新增 `progressSegments` 并在 `ApplyChromeState` 中翻转到达段。六步 `ColumnSpacing` 统一消费 `Launcher.Spacing.Xxxl`（32），右面板固定 528 宽。
- `Styles/SetupWizard.axaml` 以 `wizard-header`、`wizard-footer`、`wizard-divider`、`wizard-progress-segment`、`wizard-context`、`wizard-context-icon`、`wizard-panel`、`wizard-step-hint` 替换单列时代的 `wizard-body`、`wizard-agreement-document`、`wizard-agreement-consent`、`wizard-summary-divider`、`wizard-hero-badge`；选项行按样张取 `MinHeight`=64、`Padding`=14,13，基础态保留 1px 透明描边以免选中时位移，`:checked` 叠 Primary.Soft + 主色描边；指示圆改用向导自绘模板（20 圆 + 2 描边，选中换主色并显示 10 圆点），不继承共享 RadioButton 主题；复核编辑钮改为 Pencil + 文本（`wizard-summary-edit-label`）。
- 样式契约与无头测试按新解剖重写；三张向导 golden（语言、协议未读、协议已读暗色简体）重新生成。`agreementReadComplete` 随提示退出界面而移除。
- 后续步骤新增必须沿用双栏舞台；新差距（gap）优先并入 `Launcher.Spacing` 标度，不在组件命名空间新增间距。
