# ADR-018: 关于分区重设计方向（身份 Hero + 分组行）

- 状态：**已接受**（2026-08-30，用户仲裁；三方向对比后选定变体 A）
- 背景：设置页已按 ADR-013（纯列表变体 B）落地，对话框族（ADR-015）与设置向导（ADR-017）均已 M3 重设计；"关于"分区（`SettingsAboutSection`）仍为 P2 世代结构（图标+标题、7 个版本 chip 流式布局、WrapPanel 操作按钮、法律段落），与其他表面的语言脱节。
- 候选方向：A. 身份 Hero + 分组行；B. 纯列表（与 ADR-013 设置页完全一致）；C. 现有布局精修。
- 决策：**变体 A：身份 Hero + 分组行**。理由：关于页是应用的身份表面（identity surface），不是普通设置分组，值得更高强调级；同时分组行仍沿用设置页的行/hairline 语言，不破坏整体一致性。
  - **身份 Hero**：应用图标（`Assets/app-icon-source.jpg`）+ 产品名（Display 22 SemiBold）+ `aboutDescription` 副标题（`Text.Secondary`）+ 版本/构建时间徽章（chip 形态仅保留此处）。
  - **常规操作**（`aboutActionsGeneral`）：`checkUpdates` 为唯一 filled/tonal 最高强调，`officialSite`/`helpDocs`/`gitHubRepository` 为 outlined（`flat-action` 语义），WrapPanel 流式保留。
  - **版本详细信息**（`versionInfo`）：7 项（版本/构建时间/提交/构建配置/运行时/Avalonia/系统）由 chip 改为 **key-value 行列表**——标签左（`Text.Secondary`）、值右（`Typography.FontFamily.Monospace`），行间 inset hairline（`Color.Card.Border`，对齐 ADR-013 M3 修正 2）。
  - **法律信息**（`aboutLinks`）：版权行 + 内联"隐私政策"链接、背景图署名 + 内联"查看原始作品"链接、免责声明 caption——保留 2 个内联 `HyperlinkButton` 语义（契约要求）。
  - 范围不变：仍为设置浮层六分区之一（`IsAboutCategorySelected`），导航/归属/Z 序不动。
- Token 映射：全部值取自 `App.axaml` 既有 `Launcher.*`（间距 4/8/12/16、Radius.Md 12、Display 22、Body.Sm 13、Label.Md 12、Monospace、`Color.Card.Border/Background`、`Color.Info.Background`（chip 底）、`Button.Flat.Hover/Pressed`、`StateLayer` 8/12/16%）；**不新增 token**。
- 设计稿（primary source）：`prototypes/about-page/index.html`（双主题、纯 CSS，镜像 `Launcher.*` 值为 CSS 变量）。
- 后果：实施阶段 `SettingsAboutSection.axaml` 需重写；`UiStyleContractTests` 的绑定归属集、2 个内联法律链接、`settings-group` 根类、chip/命令顺序断言（`AboutSection_UsesSettingsGroupForTopLevelRhythm`、`AboutSection_LegalLinks_AreInlineHyperlinks`、`SettingsAboutAndAdvancedActions_UsePurposeBasedOrderAndExclusiveOwnership` 等）需按新结构同步更新；headless 分区可见性测试不受影响。

## 迭代记录：M3 融合变体（2026-08-30，用户仲裁定稿，已落地）

- 背景：`codex/redesign-about-page` 分支（横排 Hero 卡 + 双列卡，评审意见见会话记录）与 Fluent 2 对照原型（`prototypes/about-page/fluent-variant.html`）产出后，用户裁定：**借鉴 Fluent 排布思想，组件/令牌仍为 M3（Launcher.*）体系**；保留"问题反馈"链接行；不接受身份卡 caption 与 kv 行的版本信息重复。
- 决策（取代本 ADR 初版"居中 Hero"方案）：
  - **身份卡左对齐**（放弃居中 Hero 与 tinted 徽章）：图标 48（`About.AppIcon.Size`）+ 产品名（Headline.Lg 19，`about-product-name`）+ 版本 caption（`Shell.VersionCaptionText`，复合格式 `aboutVersionCaption`="版本 {0} · 构建于 {1}"，BuildTime 为空时回退 `launcherVersionLabel`）+ `aboutDescription` 副标题；操作行内收卡底：`checkUpdates`（compact filled 唯一强调）+ `officialSite`/`helpDocs`（outlined）。
  - **版本信息 kv 收为 5 行详情**（提交/构建/运行时/Avalonia/系统），版本与构建时间仅存在于身份卡 caption。
  - **新增链接行组**（组标题 `aboutQuickLinks`）：GitHub 仓库 + **问题反馈**（新命令 `OpenIssueTrackerCommand` → `LauncherConstants.IssueTrackerUrl` = 源码仓库 `/issues`），chevron 导航语义（`Button.about-link-row`，行高 40、StateLayer hover、hairline 分隔）。
  - 徽章/chip 形态退役：`Border.version-chip` 样式与 `VersionChip.Padding/Margin` token 删除（`chip-text` 保留，日志查看器仍在用）；死键清理：`aboutActionsGeneral`/`commitLabel`/`buildConfigurationLabel`/`buildTimeLabel`/`platformLabel` 删除，新增 `aboutVersionCaption`/`aboutQuickLinks`/`issueTracker`（资源总数 534→532）。
  - `ShellViewModel` 清理：删除 `CommitShaText`/`BuildConfigText`/`PlatformText`/`BuildTimeText`/`LauncherVersionValue`/`BuildTimeValue`，`AvaloniaVersionText` 语义为裸版本号，新增 `VersionCaptionText`；保留 `CommitShaValue`/`BuildConfigValue`/`PlatformValue`。
  - 记录性偏差：导航激活仍为 SecondaryContainer（ADR-013）、焦点单环 FocusRing、动效 167ms（ADR-016）——Fluent 的 SelectionIndicator/双环焦点/32px 密度不采纳。
- 设计稿（primary source）：`prototypes/about-page/m3-fluent-blend.html`（双主题；Fluent 对照件 `fluent-variant.html` 与 codex 分支 `codex/redesign-about-page` 保留为决策素材）。
- 验证：本地化契约、`dev.ps1 ui`（143 风格契约 + 137 headless 全绿，含新结构断言 `AboutSection_RendersIdentityCardKeyValueRowsAndLinkRows`）通过；headless 真实渲染截图自查通过。
