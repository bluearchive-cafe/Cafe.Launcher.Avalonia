# ADR-001：底栏形态仲裁标准（Q18）

- 状态：✅ 已接受（2026-08-25，P2 决策 Round 1）
- 日期：2026-08-25
- 相关：spec §5（Q12/Q18）、§8（AA 豁免区）

## 背景

底栏在「浮动玻璃胶囊」与「M3 贴边底栏」之间二选一，画廊双原型（Q11/§9）需要先有评判标准，否则比较会退化为观感偏好。

## 决策

四标准等权打分：①信息可读性（scrim 叠加后 text-on-scrim 对比度达标）；②三态一致性（控制 / 进度 / 安装三个面板形态统一）；③壁纸主体不被遮挡；④键盘可达性。

**标准①设一票否决**：不达标即落选。

## 后果

- 原型完成后按四标准逐项打分并附证据；若浮动玻璃胶囊在暗色壁纸最小 scrim 下读不清，直接落选 M3 贴边。
