# ADR-001: 底栏形态仲裁标准（Q18）

- 状态：**已接受**（2026-08-25，P2 决策 Round 1）
- 背景：浮动玻璃胶囊 vs M3 贴边底栏，需在画廊双原型（Q11/§9）仲裁前先锁定评判标准。
- 决策：四标准等权打分；**标准①（信息可读性，scrim 叠加后对比度专项）设一票否决**——
  1. 信息可读性（scrim 叠加后 text-on-scrim 对比度达标）；
  2. 三态一致性（控制/进度/安装三个面板形态统一）；
  3. 壁纸主体不被遮挡；
  4. 键盘可达性。
- 后果：原型完成后按此标准逐项打分；若浮动脉胶囊在暗色壁纸最小 scrim 下读不清 → 直接落选 M3 贴边。
- 相关：spec §5（Q12/Q18）、§8（AA 豁免区）。
