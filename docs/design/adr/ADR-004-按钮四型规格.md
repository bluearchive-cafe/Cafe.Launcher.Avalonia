# ADR-004: 按钮四型规格方向（§4，A→B→C 起点）

- 状态：**已接受**（2026-08-25，P2 决策 Round 1）
- 背景：四型映射已定（primary→filled / flat→outlined（语境可 tonal）/ text-link→text / danger→error-filled）；具体视觉规格未定。
- 决策：**「值不动、语言统一」**——四型统一：现状控件高度；圆角按 ADR-002 新字阶；`StateLayer` 叠加 8%/12%/16%（hover/pressed + focus）；聚焦环 2px；Elevation：主要容器 0 档、次要/浮动 1 档；共享模板 `LauncherBorderButtonTemplate` 保留并演进为**四型参数化模板**。
- 后果：P2 组件批次内落地；状态矩阵（ADR-007）按此规格展示；模板参数化先于组件迁移。
