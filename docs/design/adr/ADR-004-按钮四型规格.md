# ADR-004: 按钮四型规格方向（§4，A→B→C 起点）

- 状态：**已接受**（2026-08-25，P2 决策 Round 1）
- 背景：四型映射已定（primary→filled / flat→outlined（语境可 tonal）/ text-link→text / danger→error-filled）；具体视觉规格未定。
- 决策：**「值不动、语言统一」**——四型统一：现状控件高度；圆角按 ADR-002 新字阶；`StateLayer` 叠加 8%/12%/16%（hover/pressed + focus）；聚焦环 2px；Elevation：主要容器 0 档、次要/浮动 1 档；共享模板 `LauncherBorderButtonTemplate` 保留并演进为**四型参数化模板**。
- 后果：P2 组件批次内落地；状态矩阵（ADR-007）按此规格展示；模板参数化先于组件迁移。

## 落地记录（2026-08-26，P2 批次 A→C 收口）

1. **状态反馈机制**：以「预混色状态变体」实现（`Color.Primary.Hover/.Pressed`、`Button.Flat.Hover/.Pressed`、`SecondaryContainer.Hover/.Pressed`、`Error.Hover/.Pressed` 等，按 StateLayer 8%/12%/16% 混合生成），未采用运行时叠加状态层；`Launcher.StateLayer.Hover/Focus/Pressed/Selected` 保留为 token 与矩阵/未来组件预留（`Disabled.Content` 38% 已消费）。
2. **记录性偏差（有意）**：pressed 状态层为 **16%**（M3 官方 12%）——沿用 Q24 期产品值，视觉差异在容差内，基线锁定；`Selected` 24% 为备用刻度，选中态以容器色填充表达（ADR-013 定案）。
3. **模板路由**：`LauncherBorderButtonTemplate` 覆盖主操作/扁平/危险/关闭/内容链接/图标链接/社交 chip/Toast 动作/页签筛选按钮；text-link、icon-button、banner-link、toast-close 于本批收口路由（同为透传模板，值由各自样式持有）。
4. **Elevation**：主要容器 0 档不变；`Launcher.Elevation.Shadow.*` token 保持定义，消费点受 Avalonia 12.1.1 BoxShadow 无 TypeConverter 限制，见 spec §3.1 注释（次要/浮动 1 档阴影随 P3 表面评审）。

## M3 对齐备注

- 按钮四型语义映射与 M3（filled/outlined/text/error-filled）一致；产品字阶/高度/最小宽为产品自定义（ADR-002/003/005 记录在案）。
