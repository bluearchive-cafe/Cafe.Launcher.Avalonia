# ADR-055：本地化资源目录统一生成与提前校验

- 状态：✅ 已接受
- 日期：2026-11-04
- 相关：ADR-042、ADR-043

资源源实例注入已经消除了进程级测试覆盖，但字符串键、两条生成链及大量源扫描测试仍共同看守同一个键集合。采用单一 `Generate-LocalizationCatalog.ps1`，以中性 `.resx` 为集合所有者，同时生成 `LocalizationKeys` 枚举、`LauncherResourceCatalog` 和 ResourceManager。C# 的 `T/F` 只接受枚举，XAML 字符串索引通过目录适配；枚举数值不持久化。

每次普通构建运行生成器的只读 `-Check`，拒绝重复键、空文本、语言键集或占位符不一致、未知 XAML 键及过期生成产物。生成器只在验证成功后写文件，旧脚本仅转发。默认资源源首次构造时再逐项验证真实内嵌资源集，禁止卫星程序集缺项被父语言回退掩盖；测试注入的资源源仍可故意模拟缺失与格式错误。

不重新生成无人消费的逐条字符串属性：类型化枚举与现有本地化入口提供同样的编译保护，且不用在语言切换时替换目录实例。保留注入适配器和运行时资源集/区域语言集成测试，把生成规则的验证集中到生成器的成功、失败与只读检查用例。
