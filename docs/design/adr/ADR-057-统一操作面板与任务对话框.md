# ADR-057: 统一操作面板与任务对话框

- 状态：已接受（2026-11-07，用户完成 grilling 并确认实施）

底部随安装、就绪、进度变化的三套布局占用不同空间，停止与结果主要依赖 Toast，也使后台任务缺少持续入口。改为稳定的操作面板承载必要状态与入口，任务对话框承载安装路径草稿、详细进度、任务控制和常驻结果；复用现有 `DialogSurface` 与游戏操作旅程，不引入任务历史或新的执行调度层。

收起与停止明确分离：用户开始任务时打开对话框，自动续传保持收起；收起后完成只通知一次，不强制弹框。可见对话框原位进入结果，任务收尾完成前保持执行门禁。结果只存在于本次会话，新的准备页面不替换旧结果，实际开始下一任务才替换。保留卸载执行中不可关闭的例外。

本决策取代 ADR-016 中底部安装／控制／进度布局连续转换的条款；其余 Fluent 动效原则、M3 视觉与模态规则继续有效。行为契约归 [CONTEXT.md](../../../CONTEXT.md#游戏任务对话框)，视觉规格归 [设计规范](../design-system-spec.md#41-主窗口标题栏与任务表面)。


## 2026-11-08 修订：执行与结果采用轻量悬浮卡片

用户确认 HTML 设计后，将安装、更新、修复的执行与结果从模态对话框迁到右下角拆分按钮上方的 320 DIP 非模态卡片，间距 16 DIP、右缘对齐。完整阶段导航和路径明细从默认视图移除，详情向上展开；保留主界面壁纸空间和原主操作位置。安装准备仍用对话框，停止仍须确认，执行准入、暂停能力、路径、续传和收尾所有权不改变。

进度按当前阶段计量，并补充校验文件计数与文件内部读取进度；速度平滑后只估算下载剩余时间。30 秒无实际推进提示不改变执行结果。前台可见结果原位保留；覆盖时通知一次，后台完成在恢复前台后通知一次。主按钮按任务／状态命名，成功可手动开始游戏。该修订替代本 ADR 原文中执行进度和结果由任务对话框承载的部分；原型见 `prototypes/progress-inline-design/`。

## 2026-11-08 后续修订：移除折叠并精简常驻信息

按用户后续要求，卡片移除折叠／展开与文件详情列表，采用固定紧凑布局。下载直接显示已下载大小／总大小和速度；暂停保留大小，检查与校验保留文件计数，不再显示下载剩余时间。暂停、停止、日志、重试与结果关闭直接放在标题旁；结果摘要最多两行，完整消息通过工具提示与日志查看。主按钮和通知的任务入口仅返回卡片，执行门禁与停止确认等行为不变。本修订替代上一节关于展开详情、逐文件显示与下载时间估算的呈现条款；原 HTML 保留为历史设计证据。

## 2026-11-08 后续修订：移除主操作左侧文字组

按用户截图选中的元素树节点，删除主操作左侧同时承载操作摘要与游戏会话状态的 `StackPanel`。不增加替代控件，保留主按钮、任务悬浮卡片和底部可选状态栏的位置；会话看护及托盘状态不受影响。
