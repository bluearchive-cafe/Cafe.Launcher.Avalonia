# ADR-014: 对话框 / Toast / 设置向导 M3 重设计方向

- 状态：**已接受**（2026-08-26，P3 剩余表面第一批；用户指定范围为对话框 + Toast + 设置向导）
- 背景：设置页 M3 重设计（ADR-013）已落地。主壳首页仍处于搁置状态（无既定蓝图），本次不触碰；诊断/日志/资源面板按 Q3 保持仅 token 兼容。用户要求重设计"工作区其他界面"，即在设置页之外的三类常驻交互表面。
- 决策：
  - **对话框族（确认 / 通知 / 更新 / 错误）**：沿用统一 `Border.dialog` 表面（`Radius.Lg` 16 + `Elevation.Shadow.Lg` + `Dialog.Background`——Q13 表面中性；中性策略=种子跟随时由 scheme neutral 覆盖，见 spec §3.4）；结构 = 头部（icon + 标题 + 关闭 ✕）→ 可滚动内容 → **`dialog-footer` 底部 hairline 操作带**。取消/次要操作在左，确认/危险确认在右；无特殊强调的确认对话框默认焦点落在安全操作。
  - **Toast**：**删除自动消失进度条**；自动消失继续由时长管理（`DurationMs` 不变），不再以可视进度表示。仅保留"操作执行中"的 indeterminate 进度条（底部边缘，厚度沿用现有 token）。关闭按钮命中区域提升到 36px（`Launcher.Control.Height.Setting`），图标尺寸 16 不变。
  - **设置向导**：复用设置页导航语言——左侧 `settings-navigation-pane` + 顶部 header（"Setup Wizard"，`setupWizardStepTitle`）+ `settings-navigation`（激活态 = SecondaryContainer 填充 + 步骤号/标签）；右侧内容区照旧，底部动作带统一为 `dialog-footer`（上一步 / 下一步 / 完成）。语言 ComboBox 改走 `ComboBox.setting-control` Field 形态。
  - 不做：资源面板、日志查看器、调试面板、主壳首页/底栏（Q3/Q18 范围外或已搁置）。
- 后果：`ConfirmDialog` 与手工对话框的底部动作带统一为 hairline footer；Toast 基线、确认对话框基线需重新生成；`UiStyleContractTests` 与 headless 测试按新结构更新。
