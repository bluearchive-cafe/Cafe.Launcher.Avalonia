# ADR-065：单窗口多游戏管理

- 状态：已接受（2026-11-16）
- 日期：2026-11-16
- 相关：[ADR-044](ADR-044-游戏与产品身份由档案声明并注入.md)、[ADR-026](ADR-026-停止意图由游戏操作域翻译.md)、[ADR-031](ADR-031-启动后行为可配置且退出不走关闭路径.md)、[ADR-049](ADR-049-Linux保留单一数据根并统一小写目录名.md)、[ADR-052](ADR-052-已保存设置的派生效果只有单一归属.md)、[ADR-066](ADR-066-设置编辑与背景配置按游戏范围隔离.md)
- 行为契约：[CONTEXT.md「多游戏管理」](../../../CONTEXT.md#多游戏管理)
- 视觉规格：[设计规范 §4.1](../design-system-spec.md#41-主窗口标题栏与任务表面)

## 背景

档案注入（ADR-044）已经把官方协议、目录名与入口从消费方收回档案，但设置条目、下载检查点、公告状态和游戏会话仍只面向蔚蓝档案。用户要求一个 Cafe Launcher、同一窗口管理蔚蓝档案日服与星塔旅人国服，两款游戏各自具备安装、更新、修复、启动和卸载能力，同时保留现行 Fluent 2 壁纸首页，不采用参考仓库未提交的海报式首页。

## 决策

1. **身份先于显示**：每款游戏使用随程序发布的不可变 `YostarGameProfile` 与稳定 `RuntimeId`（`blue-archive-jp`、`stella-sora-cn`）识别。设置条目键、私有路径、快捷方式、跨进程请求和通知都使用稳定身份；本地化名称、官方区服 tag、列表位置与当前选择不承担身份。未知身份直接拒绝，不回退到蔚蓝档案。能力（Cafe 下载源、资源面板）由 `LauncherGameDefinition` 随程序声明，页面选择不能扩展支持范围。
2. **每游戏一个长期上下文**：`LauncherGameContext` 固定绑定协议客户端、本地安装状态、安装路径、状态快照服务、进程跟踪、运行环境、公告已读状态与私有路径。切换条目只改变呈现并持久化 `lastViewedGameId`；不替换或释放上下文，不把后台任务、进程会话和迟到回调改绑到新条目。
3. **全局单一文件任务**：安装、更新、修复与卸载在整个启动器内串行，暂停和「正在停止」仍占任务位，清理与刷新结束后才释放；不实现队列。另一款游戏的文件任务不阻止本游戏启动；目标游戏自身有文件任务时拒绝其启动请求。
4. **单一数据根与版本化设置**：继续使用一个启动器数据根和一份 `settings.json`。检查点、公告状态、运行器输出、兼容环境预检与前缀元数据位于 `games/<gameId>/`，受管兼容前缀位于 `compatibility/<gameId>`，安装目录按游戏独立。设置文档带 `formatVersion` 与全部受支持游戏的条目；旧无版本单游戏文档迁移为蔚蓝档案条目并保留 `settings.pre-multigame.json`，旧单游戏检查点只向蔚蓝档案迁移一次并写入迁移标记；不持续双写旧格式。
5. **明确目标的跨进程启动**：快捷方式与第二实例使用 `--launch-game --game-id <runtimeId>`。裸 `--launch-game` 固定映射蔚蓝档案，不读取当前页面；重复、缺值、未知或格式错误的参数整体拒绝。已有实例运行时转交唯一所有者，并按目标条目重新准入；受阻时给出提示，不关闭对话框、不丢弃草稿、不排队延后启动。
6. **首页保留 Fluent 2 壁纸外壳**：56 DIP 左栏顶部为游戏图标选择器，选中用强调色轻底、不使用移动指示条；后台任务入口显示任务所属游戏的进度摘要；栏底为启动器设置。左上为当前游戏的官方标志（无官方字标时使用品牌文字），其右侧齿轮打开固定目标游戏的设置。资讯、右下操作卡与任务悬浮卡继续沿用现行 Fluent 2 结构与行为。
7. **退出按进程协调**：最小化或托盘隐藏保留所有游戏的下载和会话看护；真正退出先封闭新入口，再等待各游戏任务收尾，检查点去留沿用停止意图。某款游戏选择启动后退出而另一款仍有文件任务时改为最小化。

## 取舍与后果

- 相较每款游戏单独发行或每游戏一个窗口，统一入口需要状态隔离、服务所有权与迁移成本；换来单一产品、单一更新通道和清晰的任务身份。
- 不采用可变的「当前游戏」单例：切换后到达的请求、保存与重试无法安全归属。独立上下文增加装配成本，但让任务与生命周期有唯一所有者。
- 全局串行降低首版调度与资源竞争复杂度；代价是暂停 A 后不能同时下载 B，并行任务与队列留待以后单独立项。
- 单一设置文件保留既有草稿事务与唯一写入方（ADR-024）；分游戏状态避免恢复错游戏。旧格式不双写，降级需手动恢复备份。
- 游戏上下文的图标与显示名称属于呈现层；Core 只暴露稳定身份与档案，不引入新的插件或外部档案机制。
- 参考仓库的浮动游戏栏与海报首页不作为本仓库视觉基线；本仓库沿用 Fluent 2 左栏、壁纸首页与既有任务卡。

## 验收

- 单元契约：`GameContextRegistryTests`、`GameFileOperationCoordinatorTests`、`GameDataPathsTests`、`GameLaunchArgumentsTests`、`CrossProcessGameLaunchChannelTests`、`SettingsDocumentCodecTests`、`SettingsMigrationTests`、`GameSettingsTests`。
- 无头回归：游戏栏选择与选中态、跨游戏后台任务摘要与返回、未保存草稿／模态阻止切换、按游戏设置目标、跨进程启动受阻提示、中文与四语言黄金基线。
- `pwsh ./verify.ps1` 覆盖构建、单元测试与无头测试；Windows 实机进程、快捷方式与反作弊行为仍需按平台发布清单验证。
