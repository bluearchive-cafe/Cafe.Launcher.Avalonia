# 设置页细化实施计划

- 日期：2026-11-01
- 状态：外观页视觉稿已确认，第一批外观页已实施；其余设置分类待后续分批落地。
- 基线：`5cffc37f`（跨功能组件视觉统一）。

本轮细化设置页的信息层级、阅读密度与操作反馈。沿用六个分类、分组列表和现有设置事务，以外观页作为首个完整样例。主界面布局继续保留；组件尺寸、配色和状态沿用 [ADR-050](adr/ADR-050-跨功能共享组件视觉基准.md)。

## 目标与边界

1. 用户进入分类后，能区分常用选项、相关操作和高级参数，说明文字贴近它解释的选项。
2. 通过分组、条件显示和按需展开减少默认信息量；保留 14 DIP 正文、40 DIP 标准控件和设置行的自适应换行。
3. 六个分类继续使用现有稳定 code。当前分类标题、关闭按钮与保存区保持固定，长内容在正文中滚动。
4. 设置编辑继续使用设置草稿、设置快照和统一保存；外观继续沿用即时预览、保存与放弃改动的流程。分类重排不改变字段默认值、选项含义或应用时机。
5. 页面重排集中在 UI 程序集；用户追加的静音选项单独新增兼容的持久化字段，其他设置格式、下载和游戏操作流程保持原契约，不引入新的 UI 框架。

领域与写入规则以 [CONTEXT.md](../../CONTEXT.md)、[ADR-024](adr/ADR-024-已保存设置唯一写入方.md) 为准，列表布局沿用 [ADR-013](adr/ADR-013-设置页重设计方向.md)。本计划是后续实施安排，不替代这些现行契约。

## 第一批 外观页完整样例

### 内容层级

- **主题与动效**：外观主题与动态效果，先让用户确定整体呈现方式。
- **背景**：背景来源 → 当前来源的选择／清除操作与文件摘要 → 适配方式 → 按条件显示的填充色或视频音量。相关控件紧邻，来源切换后的下一步清楚可见。
- **主题配色**：主题色模式 → 壁纸色板或自定义色。保留已有色板刷新、选中态与取色失败反馈。
- **高级配色**：取色算法、配色变体、中性色策略及种子跟随提示。取色算法仍按现有壁纸模式条件出现；其他配色参数不会因切换种子来源而被错误隐藏或重置。

### 即时预览

按用户后续要求移除独立的“预览效果”展开区。外观变更继续通过原有流程即时应用到主窗口，背景组保留共享静态图源的缩略图；不新增播放器、设置草稿或取色流程。

高级配色的展开状态只属于设置会话，不参与设置脏态或持久化；收起后保留编辑值，并将隐藏内容中的键盘焦点归还标题。

### 说明与反馈

保留会影响选择的解释与风险说明；常用枚举选项使用清楚的标签，避免标题和说明复述同一句话。长路径显示摘要，并保留查看完整路径的方式。字段错误靠近字段，保存错误靠近保存结果；对话框继续承担需要用户确认的动作。

## 验收标准

### 可见性与可操作性

- 六分类中的现有选项、命令、风险说明与法律信息均有可达入口。
- 常用选项在高级参数之前；折叠不清空值，也不隐藏当前错误的恢复入口。
- 分类标题、关闭按钮和保存区始终可达；正文允许滚动，最小窗口下字段和按钮自然换行。
- 按钮遵守共享角色与密度，不为单页增加独立的颜色、圆角或焦点配方。

### 状态与回归场景

- 仅展开／折叠／切换分类时，草稿值与保存按钮启用态保持不变。
- 修改外观 → 快速切换来源或配色 → 保存，最终显示与持久化均对应最后一次选择。
- 修改外观 → 放弃／未保存确认 → 恢复设置快照，背景、配色及音量一致恢复。
- 保存期间的禁用、保存失败后的编辑恢复、关闭时的在途预览收尾保持正确。
- 设置打开期间其他既有写入方更新设置后，保存不把已同步字段写回旧值。
- 使用真实 Tab、Shift+Tab 和 ESC 走查；收起分组、保存和关闭后焦点有明确落点。

### 窗口 语言与主题

六分类逐一覆盖，检查简体中文、繁体中文、日语、英文，明暗主题，1300×754 与 1024×640，以及 100%／125%／150% 文字倍率。长路径、较长操作标签、带说明的行和展开高级配色优先覆盖组合边界；OS DPI 与真实多显示器缩放另做实机走查，不用文字倍率测试代替。

### 验证入口

- 针对改动运行现有 `SettingsViewModelTests`、`SettingsEditorTests`、`SavedSettingsWriterTests`、设置与预览相关 ViewModel 测试；仅为新增交互补聚焦回归。
- XAML／样式和实际布局通过 `pwsh ./dev.ps1 ui`；新增文案通过本地化生成与契约检查。
- 有意视觉变更通过 `pwsh ./test.ps1 -UpdateGolden` 更新基线，并逐张检查有意图差异。
- 每批交付前运行 `pwsh ./verify.ps1`，记录通过项和实机验证边界，核对锁文件 RID 副作用。
- 同步更新 [设计规范](design-system-spec.md) 与 [走查清单](design-walkthrough-checklist.md)；只有已实施的决定进入现行规格。
