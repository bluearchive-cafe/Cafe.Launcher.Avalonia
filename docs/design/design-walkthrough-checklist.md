# 设计走查清单（Design Walkthrough Checklist）

> 状态：**落地**（随 P2 C 批交付；[ADR-008](adr/ADR-008-组件批次映射.md)）。
> 用途：P3 每表面完成时人工复核的实物载体（spec §9）；与 [design-system-spec.md](./design-system-spec.md) §3.5 状态矩阵、§7 豁免区共同维护。
> 复核方式：逐项走查并记录结果（✓ / ✗ / 备注）；新增表面或调整组件后更新本清单。

## 1. 组件状态矩阵（spec §3.5）

矩阵实物 = Debug 构建「设计画廊 → 组件状态矩阵」（3×6 以上：四型按钮 / 卡片含 Toast 卡 / 设置行 × normal / hover / pressed / disabled / focus-visible / invalid）。
走查时打开画廊逐格与生产样式对照：

| 组件 | normal | hover | pressed | disabled | focus-visible | invalid |
|---|---|---|---|---|---|---|
| Filled 按钮（`primary-action`） | ✓ | ✓ | ✓ | ✓ | ✓ | 不适用（留空） |
| Outlined 按钮（`flat-action`） | ✓ | ✓ | ✓ | ✓ | ✓ | 不适用（留空） |
| Text 按钮（`text-link`） | ✓ | ✓ | ✓ | ✓ | ✓ | 不适用（留空） |
| Error-filled 按钮（`danger-action`） | ✓ | ✓ | ✓ | ✓ | ✓ | 不适用（留空） |
| 卡片 / Toast 卡 | ✓ | ✓ | ✓ | ✓ | ✓ | 不适用（留空） |
| 设置行（Select 输入） | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

- 状态层不透明度产品值：hover 8% / focus 12% / pressed 16% / disabled 内容 38%（`Launcher.StateLayer.*`；pressed 16% 为产品值，M3 官方 12%——记录性偏差，见 ADR-004 落地记录）。
- 状态反馈以「预混色状态变体」实现（`Primary.Hover/.Pressed`、`SecondaryContainer.Hover/.Pressed` 等），未采用叠加状态层机制（ADR-004 落地记录）。
- 向导组件（ADR-017）随审计-0828 对齐本矩阵：`wizard-action.primary-action` 补齐 filled 禁用态（预混配方），`wizard-option` 键盘聚焦铺 token 焦点环。
- 焦点环（`FocusRing` 为不透明强调色，对比不足时回退 M3 `OnSurface`；选中下拉项用对应状态的 `OnSecondaryContainer` 在容器内绘制焦点）逐表面复核：明/暗主题 + 壁纸模式目测 ≥3:1 可辨识（含 banner 箭头、chrome 态区域）；动态实心表面配对由 `MaterialSchemeGeneratorTests` 覆盖；壁纸部分仍需人工复核。
- **焦点环只应在键盘导航时出现（ADR-040）**：打开对话框/叠层、鼠标点击后都**不得**出现焦点环；按 Tab / 方向键才出现。框体框架默认的焦点矩形（`FocusAdorner`）已全局关闭，应用用各控件的 `:focus-visible` 规则自绘。走查时按一次 Tab 确认焦点可见，再关掉叠层确认没有残留的环。

## 3. 表面级走查（P3 顺序）

### 3.1 主壳（首页）——整体布局搁置；就绪态按钮局部调整（2026-11-01）
- 首页整体仍无既定蓝图（2026-08-25 用户撤销首页设计决策，ADR-012 历史记录）；就绪态入口按 spec §4.1 合并为启动分体按钮。
- 普通与仅按钮布局：主区单击直接启动，右侧省略号仅展开游戏管理菜单；两区共享主色和外轮廓，悬停/按下分别反馈，菜单打开时右区保持反馈。
- 菜单右缘与按钮右缘对齐，向上展开并间隔 8 DIP；在默认/最小窗口检查位置，在屏幕边缘检查原生避让。展开截图基线为 `launch-split-menu`。
- Tab 停靠一次，Enter / Space 启动，Alt+↓ / F4 打开菜单，Escape 收起并恢复焦点；忙碌时两区都禁用。卸载单独分隔，既有确认流程保留。
- 检查亮暗主题、四语言与文字放大后的标签、分隔线和整体焦点环；自动化截图见 `launch-split-button` / `launch-split-button-dark-zh`，真实鼠标、屏幕阅读器与 DPI 仍需人工复核。

### 3.2 设置页（ADR-013）
- 两列自顶到底：导航列 header（「设置」标题）+ 内容区标题行右端 ✕（`content-header-action`）；不重复显示分类副标题。
- 导航选中 = `SecondaryContainer` 填充 + `OnSecondaryContainer` 文字 + leading icon，无指示条；hover/pressed 用 `.Hover/.Pressed` 变体。
- 内容区 = 纯列表 + 组间空档 + 行间 0.5 DIP hairline（`Color.Card.Border`，左缘对齐 16px 文本缩进）。
- 覆盖层 = `Dialog.Background`（中性策略=种子跟随时由 scheme neutral 覆盖）+ `DialogSurface` 的 16 DIP 组件圆角 + 克制的双层 `Elevation.Shadow.Dialog`。
- 控件统一 Field 形态（`Field.Background`/`Field.Border`/`Radius.Sm`/2px 聚焦环）；Field.Border 双档 ≥3:1（Light `#8290A5` / Dark `#7B89A0`）。
- 底部操作带（取消 / 保存）语义与焦点默认落在安全操作。
- 外观页按「主题与动效 → 背景 → 主题配色」排列；动态效果在外观中只有一个入口。图片、文件夹、视频、清除及完整路径 tooltip 均可达；填充色与音量按原条件显示。
- 高级配色默认收起；展开、收起、切换分类不会改变草稿或启用保存，重新打开设置复位。编辑高级选项后收起／再展开保留值；焦点在内容中时收起，回到标题并保持可见的键盘焦点。
- 明暗主题下悬停／按下展开标题时，整行使用共享中性状态色，不出现额外黑白外框或箭头底块；展开、禁用和键盘取焦不改变标题尺寸。
- 页面没有独立效果预览区；背景缩略图与主窗口即时预览随草稿同步，主窗口保持唯一视频播放表面。文件加载失败时提示和重新选择入口无需展开，切回内置后提示清除。
- 选中自定义视频后，音量行显示静音复选框；静音立即生效且保留滑块值，静音期间调整音量仍不出声，取消静音恢复新音量。保存后重开保留静音状态，放弃改动恢复快照；切换图片或其他来源后该行隐藏。
- 在四语言、最小窗口及文字放大下，将音量切换到 0%、35%、100%，确认百分比槽宽度固定、静音选项位置不变，文字完整且右对齐。

- 提交式布尔选项和资源选择均为复选框，改变选中状态后仅草稿变脏；保存后保留，取消可恢复。外观页明确即时预览可撤销。
- 路径草稿有变更时，当前安装区仍显示实际维护目录，目录/修复/卸载入口禁用且说明原因；恢复原路径或保存后重新可用。
- 主题色板用单选语义，可通过键盘切换并更新当前索引；可见焦点不改变色块尺寸。
- 视频音量滑块在亮暗主题与自定义主题色下使用相同 Primary 家族，焦点可见，禁用态可辨认。
- 资源面板有未保存资源选择或 UID 输入时，关闭/ESC、刷新与切换来源先确认放弃；取消保留值与来源，确认才继续；保存中不可继续修改资源选择。
- 关于页优先显示常用动作与链接，五项技术信息默认折叠，展开后内容可滚动且键盘焦点不会留在隐藏内容中。

- 默认与最小窗口下，从滚动后的分类切到其他分类，正文回到顶部；键盘焦点留在导航，草稿与高级配色展开状态保留。
- 修改后跨分类仍显示未保存状态；保存等待时显示「正在保存…」与不定进度，操作禁用；成功后清除提示，失败后恢复提示并可重试，放弃后清除。
- 下载与网络先呈现下载源/限速，再呈现代理/HTTP/2；高级将日志诊断与数据目录/重置分组，重置确认与危险样式保留。
- 四语言、亮暗主题和文字放大下核对底栏状态换行及按钮边界；自动化已覆盖四语言 100%/150%/200%，真实系统 DPI 与读屏器仍需人工走查。

### 3.3 对话框族（ADR-015 外壳 / ADR-040 动作）
- 确认/通知/更新/错误四类统一解剖：头部（icon + 标题 + ✕）→ 可滚动内容 → `dialog-footer` hairline 操作带；危险确认用 `danger-action`。
- **动作顺序（ADR-040，Fluent/WinUI）**：do-it（确认 / 下载 / 导出）在**最左**，安全动作（取消 / 稍后 / 关闭）在**最右**——与「取消左、确认右」相反。
- **默认按钮（ADR-040）**：非破坏性确认的确认动作是默认按钮（强调填充 + Enter + 打开时初始焦点）；破坏性确认（`IsDangerConfirm`）**不设默认按钮**，初始焦点仍在安全动作上，Enter 不会触发破坏性操作。
- **动作底色与边框（ADR-040）**：次要动作不再是透明描边，而是中性静止填充（`Launcher.Color.Dialog.Action.Background`）；动作带按钮无可见边框，且焦点环的 2px 厚度**常驻预留**（聚焦只改颜色，几何不动）。
- **焦点视觉（ADR-040）**：只在键盘导航时出现（程序式聚焦与鼠标点击不画）；框架默认焦点矩形全局清掉，焦点环由各控件既有 `:focus-visible` 规则绘制。
- 明示关闭路径完整：✕ 按钮 + 取消/次要操作按钮；不依赖手势或仅有遮罩交互的路径。
- 禁用态的既有约定不变：禁用按钮保留 1px 描边（`PrimaryActionButtons_..._DisabledStatesKeepTheirBorders`）。

### 3.4 Toast（ADR-014）
- 无自动消失进度条；仅操作执行中显示 indeterminate 进度条（底部边缘，厚度 token）。
- 关闭按钮命中区 ≥36px（`Launcher.Control.Height.Setting`）；图标 16px。
- 严重性四色（成功/警告/错误/信息）与系列卡对比度 ≥3:1（契约测试锁定）。

### 3.5 设置向导（ADR-059）
- 模态 `DialogSurface`（920×480）内五段表面：全幅头部（标题 + `setupWizardStepProgress` 计数 + `wizard-skip` 跳过 + 六段进度轨）→ 发丝线 → 滚动正文舞台 → 发丝线 → 全幅动作带（`wizard-action`：上一步在左，下一步·完成在右，`MinWidth` 100，主操作叠 `primary-action`）。头部与动作带贴表面边缘，留白只由样式 token 承担。
- 正文舞台 = 860 固定宽（300 左引导 + 32 间距 + 528 右面板），六步共用同一结构，仅右面板随步骤变化。左引导 = 56 圆形语义图标 + 步骤标题 + 说明；右面板为 `wizard-panel` Card，承载语言选择、协议阅读器、路径输入与状态行、`wizard-option` 选项行或复核摘要行；协议步面板自管留白，读者区独占滚动。
- 下载源/代理选项 = `wizard-option` 单选列表行（最小行高 64、整行等宽拉伸命中、悬停/按压/禁用/焦点态齐备、选中取 Primary.Soft + 主色描边、自绘 20 圆单选圈左缘跨行对齐）；路径状态 = `wizard-status-row`（图标 + 语义色文本，色彩非唯一信号）；语言与路径字段在控件上方标注字段名；复核 = `wizard-summary-row` + hairline 分隔 + Pencil「修改」，最后一步 Footer 切「完成」。
- 协议步骤：左引导追加版次胶囊与语言声明；`AgreementScrollViewer` 为唯一滚动区，同意项固定在面板底栏，滚动提示仅保留为 `AutomationProperties.HelpText`，勾选门禁由滚动到底驱动。
- 完成确认态：最后一步（复核）即完成态，中性标题配 Success 徽章和勾号，无庆祝动画、不缩放。
- 动效（ADR-016/017/059）：步骤切换 = 顺序换页——空间档 333ms 对半分：旧内容 166.5ms 加速淡出（禁命中）→ 中点换内容并复位滚动、壳层（步骤进度文本、进度轨到达段 + 动作钮可见性）同帧随显示步翻转 → 起势帧渲染入场 pose（消化首次布局）→ 新内容 166.5ms 减速淡入 + ±14px 方向滑入（透明度与位移同批 `DoubleTransition`，收尾留缓冲再结算）；快速连点最新状态生效；外壳遮罩 Fast 淡入、表面单次进出场；降动效瞬切换面并定格。

### 3.6 诊断/日志（Q3 例外声明）
- 仅 token 兼容；列表维持 Fluent 基础模板；不做 M3 视觉重设计。

### 3.6b 资源面板（ADR-041）
- 外层骨架 = `DialogSurface` Panel 形态不动（头带 / 滚动正文 / 发丝底带，ADR-015）；正文解剖已 M3 化：UID 单卡三态（展示 / 编辑 / 缺失互斥面板，UID 值等宽 + 字距）、来源 = MD3 分段按钮（`RadioButton.segment-option`，选中段 accent 家族 + 勾选图标）、条目 = 单卡三行（`Border.resource-row` + 发丝分隔线，行 = 标题 + 状态 chip + 版本行 + 无标签 Switch）。
- 分段控件的独立胶囊焦点层不参与测量；四语言、亮暗主题及 100%／150%／200% 文字下往返取焦，段宽、组边界、相邻位置和选择值保持不变。
- 状态 chip：Ready=Success/`Success.Soft`、Waiting/Loading=Secondary/`Content.Row`、Failed=Danger/`Danger.Soft`；类映射由 `ResourcePanelItem` 的四个表象布尔驱动。

### 3.7 崩溃窗口（ADR-019 / ADR-020，独立 Fluent 设计系统）
- 设计系统边界：`Crash.*` 令牌就近定义在 `CrashReportWindow.axaml` 的 `Window.Resources`（Light/Dark 两档），**不引用 `Launcher.*`**；`CrashReportApp.axaml` 注册 `FluentTheme` + `MaterialIconStyles`（缺后者图标渲染为空白）。
- 信息层级（A 版原型）：状态行（危险色）→ 标题 20 → 说明 15 → 摘要行（编号/时间/版本/提交）→ 默认折叠的技术详情 → 动作带。
- 构建身份：摘要行的「提交」显示快照记录的构建 SHA（与关于分区同源、全量 40 位）；技术详情首部同样带 `Commit:` 行。
- 动作只有三个：打开日志目录（指向 `unified.log` 所在数据目录）、复制详情、退出启动器；不提供继续/重启/在线上传。
- 尺寸与对齐：700 固定宽、高度随内容、不可缩放；展开详情只增高不变宽；按钮内容居中、详情卡片满宽、状态/标题/说明左缘对齐。
- 复核要点：明/暗两档 `Crash.*` 对比度人工目测（正文 ≥4.5:1、按钮与边框 ≥3:1）；布局改动后按 README 流程重生成黄金截图基线并复核截图；`Crash.*` 不得外溢到其他视图。

## 4. 文字、布局与状态验证（2026-10-24）

- 自动化：四语言 × 默认/最小窗口 × 100%/125%/150% 控件文字 × 亮暗主题，遍历六个设置分类，检查说明与操作不重叠、操作控件不超出行宽、说明不裁切及保存/取消等高。首页用已加载的长状态文案覆盖统一操作面板，任务对话框覆盖安装准备，悬浮卡片覆盖进度和结果；验证默认字号和最小窗口 150% 文字下元数据与动作可见。
- 顶部对齐：四语言 × 100%/150%/200% 控件文字，遍历六个设置分类，检查「设置」、当前分类标题和关闭按钮的垂直中心一致。
- 回归：实心主/危险操作的键盘焦点描边与填充 ≥3:1；空说明不占位，无说明的选择框/开关行在 100%/150% 文字下标题和操作均居于整行垂直中心、操作上下留白对称；竖排的选择框/多按钮操作组在无简介、有简介和有提示时均保留令牌定义的 8 DIP 底部内缩；窄→宽→窄切换保留控件实例、焦点和选中值，恢复横排后行高与居中不变；动态 Primary/SecondaryContainer 的正常、悬停、按下文字对比度，以及中性表面/选中导航焦点色对比度。
- 截图：补最小窗口 150% 简中深色设置与 Fidelity + 种子跟随深色外观设置黄金基线；其余可见变更同步再生既有基线。
- 仍需人工：真实 OS DPI/独立文字大小、任意壁纸下焦点可见性、屏幕阅读器、真实鼠标与键盘完整状态路径。自动化文字放大不等于这些人工项目已验收。

## 跨功能组件基准（ADR-050，2026-11-01）

- 对照设置、确认框、向导、资源面板和日志导出：同尺寸操作的字号、圆角、内缩、中性底色与禁用态一致；标准 40 DIP，显式紧凑操作 36 DIP。
- Tab 依次经过主/次/危险操作时，按钮及右对齐动作组不位移；主/危险填充上的焦点线分别用 OnPrimary/OnError。鼠标操作与程序式初始取焦仍不画键盘环。
- 浅色/深色与两种中性色策略下，次要操作正常/悬停/按下均为实底；切换策略后不残留上一套颜色。字段和取色器触发器使用同一 8 DIP 圆角。
- 确认框、表单和覆盖层同为 16 DIP 外圆角；布局按内容语义保留。主界面布局和大型任务按钮的 48/58 DIP 尺寸保持现状。
- 崩溃窗口在正常和隔离宿主中均以独立 Crash.* 呈现相同几何，按钮焦点和禁用不改变尺寸。

### 统一操作面板与任务对话框（ADR-057）

- 隐藏可选状态栏后仍保留主操作和任务入口；主操作左侧不再显示操作摘要／会话文字，托盘仍显示启动中／运行中。
- 主动执行和自动续传都在拆分按钮上方显示固定紧凑卡片，无折叠／展开；四语言、亮暗主题和文字放大下保持右对齐与 16 DIP 间距，点击主操作返回卡片且不移动主按钮。
- ESC 不关闭非模态进度卡片；停止需确认，取消确认回到卡片，停止收尾完成前不能开始新任务。
- 前台可见结果原位保留，覆盖时通知一次，后台完成在恢复前台后通知一次；旧通知不得打开新任务结果。查看结果关闭普通覆盖层时仍保留草稿确认与关键模态闸口。
- 下载直接显示已下载大小／总大小及速度，支持暂停／继续；暂停保留大小并隐藏速度。校验显示文件计数，实际读取仍参与无进展检测；30 秒无推进只提示等待。主按钮随安装／更新／修复和暂停等状态变更，成功后手动开始游戏。停止、日志和适用的重试始终无需展开即可操作。
- 安装路径草稿关闭即放弃，显式安装／识别才保存；可见失败提供适用的重试与日志入口。
