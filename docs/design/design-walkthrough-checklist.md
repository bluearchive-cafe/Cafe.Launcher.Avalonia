## 3. 表面级走查（P3 顺序）

### 3.1 主壳（首页）——无标题栏壁纸壳与图标游戏栏（2026-11-19）
- 首页由 64 DIP 纯图标游戏库侧栏、无底板顶部工具行、左侧身份区和右下主操作组成。[ADR-065](adr/ADR-065-单窗口多游戏管理.md) 定义游戏条目和后台任务的归属。
- 游戏库：Tab 进入列表，用上下方向键切换游戏。悬停或键盘聚焦图标时显示名称、区服和任务进度工具提示；后台任务与失败以 16 DIP 角标提示，不占用栏内文字。官方图标按 8 DIP 圆角裁切，与选中底和关于页应用图标的圆角一致。检查四语言、最小窗口与文字放大时圆角、角标、选中指示和工具提示可见。栏底显示诊断与启动器设置图标。
- 顶部工具行无底板、边框与标题栏底色；游戏字标或品牌文字位于内容区左上，作为标题主元素（官方字标高 80 DIP）。右侧「游戏设置」打开固定目标的设置；「资源面板」仅对支持的游戏出现。窗口按钮贴住窗口右上角，工具行右侧为其保留空间。拖动页头空白可移动窗口、双击可最大化；页头内按钮仍可单击与键盘激活。
- 标题下方状态行按「状态面板」设置显示会话、启动校验、网络、下载源和版本；隐藏时只隐藏该行，主操作不动。
- 切换游戏后，检查标题、适用入口、资讯和操作的归属。未保存草稿或顶层模态时切换应提示受阻，并保留现有对话框和草稿。
- 资讯区位于标题下方左侧，宽 476 DIP、底边与主操作底边对齐；横幅高 220 DIP 并与公告面板无缝拼接。展开资讯时主按钮仍可用，官网和社交链接位于资讯末尾。检查横幅悬停与键盘取焦时的翻页入口和自动轮播暂停。
- 主操作浮在右下角，距右/下 12 DIP；主区单击直接启动，右侧省略号仅展开游戏管理菜单；两区共享主色和外轮廓，悬停/按下分别反馈，菜单打开时右区保持反馈。
- 菜单右缘与按钮右缘对齐，向上展开并间隔 8 DIP；在默认/最小窗口检查位置，在屏幕边缘检查原生避让。展开截图基线为 `launch-split-menu`。
- 任务卡固定宽 382 DIP，右缘与按钮对齐，位于按钮上方 16 DIP；检查四语言与文字放大时标题不换行、摘要不裁切、操作按钮保持 32 DIP。
- Tab 停靠一次，Enter / Space 启动，Alt+↓ / F4 打开菜单，Escape 收起并恢复焦点；忙碌时两区都禁用。卸载单独分隔，既有确认流程保留。
- 检查亮暗主题、四语言与文字放大后的标签、分隔线和整体焦点环；自动化截图见 `shell-default`、`launch-split-button` / `launch-split-button-dark-zh` 与 `floating-task-*`，真实鼠标、屏幕阅读器与 DPI 仍需人工复核。

### 3.2 设置页（ADR-013 / ADR-066；整窗页形态见 ADR-070）
- 两个入口、同一设置页的两种范围、一次编辑会话：左栏齿轮打开启动器设置（常规、外观、默认背景、下载与网络、高级、关于）；页头右侧打开游戏设置（安装与维护、启动与运行、下载与资源、游戏背景），标题带固定目标游戏名称。页面铺满标题栏以下、图标栏右侧的区域，齿轮钮保持选中态，任务角标常驻可读。切换目标前必须先保存或放弃当前草稿。
- 保存只提交当前范围：全局保存不写游戏条目，游戏保存不写全局字段；失败恢复未保存提示并可重试。文件任务进行期间，所属游戏的配置区禁用并说明原因，另一款游戏与全局偏好仍可编辑。
- 游戏下载与资源：下载源只显示当前游戏声明支持的单选项（蔚蓝档案官方／Cafe，星塔旅人仅官方，Cafe 项与分隔线不出现）；资源入口只在支持资源面板的游戏显示。
- 游戏背景：默认关闭「使用专属背景」，关闭时展示继承的全局默认；开启后整组编辑来源与媒体，自定义图片/视频/文件夹只在开启后出现；关闭保留选择，再开启恢复。
- 固定页头显示编辑范围，关闭按钮在右端；左侧是分类，右侧在正文滚动区上方显示分类标题。底栏左侧显示保存状态，右侧承载操作。
- 使用 Fluent 默认选中指示，选中分类文字加粗。检查通过键盘切换分类时焦点可见，分类较长时能滚动到最后一项。
- 内容区使用可滚动的分组卡片列表：组标题在卡外，卡内行间以上缘发丝线分隔；以组标题和组间留白建立层级。
- 层级字重：分类内的组标题一律 `group-title`（强调字重，含「当前背景」与「高级配色」），设置行标题固定常规字重；同一组内不再重复分类说明。
- 检查设置、确认框和向导的表面在明暗主题下清晰可辨。
- 检查原生输入控件在悬停、键盘聚焦和禁用时的反馈。
- 底部操作带（放弃更改 / 保存）语义与焦点默认落在安全操作；带改动关闭或按 Esc 仍先经未保存确认。
- 外观页按「主题与动效 → 主题配色 → 高级配色」排列；动态效果在外观中只有一个入口；默认背景页单独承载背景来源与媒体选项。图片、文件夹、视频、清除及完整路径 tooltip 均可达；填充色与音量按原条件显示。
- 高级配色默认收起；展开、收起、切换分类不会改变草稿或启用保存，重新打开设置复位。编辑高级选项后收起／再展开保留值；焦点在内容中时收起，回到标题并保持可见的键盘焦点。
- 在明暗主题下核对展开标题的悬停、按下、禁用与键盘焦点。
- 页面没有独立效果预览区；背景缩略图与主窗口即时预览随草稿同步，主窗口保持唯一视频播放表面。文件加载失败时提示和重新选择入口无需展开，切回内置后提示清除。
- 选中自定义视频后，音量行显示静音复选框；静音立即生效且保留滑块值，静音期间调整音量仍不出声，取消静音恢复新音量。保存后重开保留静音状态，放弃改动恢复快照；切换图片或其他来源后该行隐藏。
- 在四语言、最小窗口及文字放大下，将音量切换到 0%、35%、100%，确认百分比槽宽度固定、静音选项位置不变，文字完整且右对齐。

- 提交式布尔选项和资源选择均为复选框，改变选中状态后仅草稿变脏；保存后保留，取消可恢复。外观页明确即时预览可撤销。
- 路径草稿有变更时，当前安装区仍显示实际维护目录，目录/修复/卸载入口禁用且说明原因；恢复原路径或保存后重新可用。
- 主题色板用单选语义，可通过键盘切换并更新当前索引；可见焦点不改变色块尺寸。
- 视频音量滑块在亮暗主题与自定义主题色下使用相同 Primary 家族，焦点可见，禁用态可辨认。
- 资源面板有未保存资源选择或 UID 输入时，关闭/ESC、刷新与切换来源先确认放弃；取消保留值与来源，确认才继续；保存中不可继续修改资源选择。
- 关于页优先显示常用动作与链接，五项技术信息默认折叠，展开后内容可滚动且键盘焦点不会留在隐藏内容中。

- 默认与最小窗口下，从滚动后的分类切到其他分类，正文回到顶部；键盘焦点留在导航，草稿与高级配色展开状态保留。
- 修改后跨分类仍显示未保存状态；保存等待时显示「正在保存…」与不定进度，操作禁用；成功后清除提示，失败后恢复提示并可重试，放弃后清除。
- 下载与网络先呈现下载速度限制，再呈现代理/HTTP/2；下载源在游戏设置中；高级将日志诊断、网络兼容与数据目录/重置分组，重置确认与危险样式保留。
- 四语言、亮暗主题和文字放大下核对底栏状态换行及按钮边界；自动化已覆盖四语言 100%/150%/200%，真实系统 DPI 与读屏器仍需人工走查。

### 3.3 对话框族（ADR-015 外壳 / ADR-040 动作）
- 检查标题、正文、底栏沿相同内边距对齐，Panel 右上角关闭按钮可达。空间不足时正文可滚动、底栏按钮按原顺序换行。
- 辅助动作在左，尾部操作在右。在窄窗口和文字放大后检查错误对话框的「查看日志」「复制详情」和主要操作，以及卸载进行中的提示和状态按钮。
- 用 Tab 核对各操作的焦点和顺序。非破坏性确认的默认动作响应 Enter；破坏性确认打开时焦点在安全动作，Enter 不触发破坏性操作。
- 在亮暗主题检查按钮的悬停、按下、键盘聚焦和禁用状态。

### 3.4 Toast（ADR-014）
- 无自动消失进度条；仅操作执行中显示 indeterminate 进度条（底部边缘，厚度 token）。
- 关闭按钮命中区 32px（`Launcher.Control.Height.Setting`）；图标 16px。
- 严重性四色（成功/警告/错误/信息）与系列卡对比度 ≥3:1（契约测试锁定）。

### 3.5 设置向导
- 在每一步核对标题、说明和表单的从上到下顺序。长步骤可以独立滚动，页头进度和底部上一步／下一步／完成保持可达。
- 在最小窗口与文字放大下核对协议阅读器、语言说明和固定的同意复选框。首次到达协议时复选框禁用，滚动到底后可勾选。用键盘验证同意后出现的跳过按钮能打开确认。
- 动效（ADR-016/017/059）：步骤切换 = 顺序换页——空间档 333ms 对半分：旧内容 166.5ms 加速淡出（禁命中）→ 中点换内容并复位滚动、壳层（步骤进度文本、进度轨到达段 + 动作钮可见性）同帧随显示步翻转 → 起势帧渲染入场 pose（消化首次布局）→ 新内容 166.5ms 减速淡入 + ±14px 方向滑入（透明度与位移同批 `DoubleTransition`，收尾留缓冲再结算）；快速连点最新状态生效；外壳遮罩 Fast 淡入、表面单次进出场；降动效瞬切换面并定格。

### 3.6 诊断/日志（Q3 例外声明）
- 仅 token 兼容；列表维持 Fluent 模板；不做视觉重设计。

### 3.6b 资源面板
- 核对 UID 展示、编辑与缺失三态，切换来源使用默认 Fluent 单选按钮。UID 说明常驻在资源列表之前。
- 核对三行资源的状态、版本与复选框。较长的状态与版本可换行；版本一致时显示一份摘要。使用键盘核对来源和资源偏好可访问，底部刷新和批量保存可达。

### 3.7 崩溃窗口（ADR-019 / ADR-020，独立 Fluent 设计系统）
- 崩溃窗口从 `Window.Resources` 获取 `Crash.*` 布局和字阶令牌；`CrashReportApp.axaml` 加载 `FluentAvaloniaTheme`，符号图标使用 `SymbolThemeFontFamily`。
- 信息层级为状态、标题、说明、摘要、默认折叠的技术详情和底栏动作。摘要显示编号、时间、版本和提交。
- 构建身份：摘要行的「提交」显示快照记录的构建 SHA（与关于分区同源、全量 40 位）；技术详情首部同样带 `Commit:` 行。
- 动作只有三个：打开日志目录（指向 `unified.log` 所在数据目录）、复制详情、退出启动器；不提供继续/重启/在线上传。
- 尺寸与对齐：700 固定宽、高度随内容、不可缩放；展开详情只增高不变宽；按钮内容居中、详情卡片满宽、状态/标题/说明左缘对齐。
- 复核要点：明/暗两档 `Crash.*` 对比度人工目测（正文 ≥4.5:1、按钮与边框 ≥3:1）；布局改动后按 README 流程重生成黄金截图基线并复核截图；`Crash.*` 不得外溢到其他视图。

## 4. 文字、布局与状态验证（2026-10-24）

- 自动化：四语言 × 默认/最小窗口 × 100%/125%/150% 控件文字 × 亮暗主题，遍历启动器设置的六个分类与游戏设置的四个分类，检查说明与操作不重叠、操作控件不超出行宽、说明不裁切及保存/取消等高。首页用已加载的长状态文案覆盖统一操作面板，任务对话框覆盖安装准备，悬浮卡片覆盖进度和结果；验证默认字号和最小窗口 150% 文字下元数据与动作可见。
- 四语言与 100%/150%/200% 文字下，范围标题与关闭按钮在固定页头对齐，分类标题紧接在下方。检查长游戏名是否换行且保留关闭入口。
- 回归：实心主/危险操作的键盘焦点描边与填充 ≥3:1；空说明不占位，无说明的选择框/开关行在 100%/150% 文字下标题和操作均居于整行垂直中心、操作上下留白对称；竖排的选择框/多按钮操作组在无简介、有简介和有提示时均保留令牌定义的 8 DIP 底部内缩；窄→宽→窄切换保留控件实例、焦点和选中值，恢复横排后行高与居中不变；动态 Primary/SecondaryContainer 的正常、悬停、按下文字对比度，以及中性表面/选中导航焦点色对比度。
- 截图：补最小窗口 150% 简中深色设置与 Fidelity + 种子跟随深色外观设置黄金基线；其余可见变更同步再生既有基线。
- 仍需人工：真实 OS DPI/独立文字大小、任意壁纸下焦点可见性、屏幕阅读器、真实鼠标与键盘完整状态路径。自动化文字放大不等于这些人工项目已验收。

## 跨功能组件基准（ADR-050，2026-11-01）

- 对照设置、确认框、向导、资源面板和日志导出：同尺寸操作的字号、圆角、内缩、中性底色与禁用态一致；标准 32 DIP，Toast 与显式紧凑操作同为 32 DIP。
- 图标：启动器自有图标使用 `FluentIcon` 的矢量轮廓，字形取 `FluentGlyphs`，尺寸取 `Launcher.Icon.*`。在浅深主题和 100%、125%、150%、200% 显示缩放下检查清晰度与图标对齐（ADR-064）。
- Tab 依次经过主/次/危险操作时，按钮及右对齐动作组不位移；主/危险填充上的焦点线分别用 OnPrimary/OnError。鼠标操作与程序式初始取焦仍不画键盘环。
- 浅色/深色与两种中性色策略下，次要操作正常/悬停/按下均为实底；切换策略后不残留上一套颜色。字段和取色器触发器使用同一 8 DIP 圆角。
- 确认框、表单和覆盖层同为 8 DIP 外圆角；布局按内容语义保留。主界面布局和大型任务按钮的 48/58 DIP 尺寸保持现状。
- 崩溃窗口在正常和隔离宿主中均以独立 Crash.* 呈现相同几何，按钮焦点和禁用不改变尺寸。

## 多游戏基准（ADR-065 / ADR-066，2026-11-16）

- 首页：切换两款游戏后，游戏栏选中底、左上 Logo/字标、资讯、状态与操作卡同步更新；壁纸、栏宽、操作区位置不动。任务卡与任务入口只指向所属游戏。
- 阻塞：设置草稿、顶层模态、目标游戏文件任务或跨进程请求受阻时，给出本地化提示且不改变当前页面、不关闭对话框、不清空草稿。
- 设置：目标游戏固定；全局保存不写游戏字段，游戏保存不写全局字段；星塔旅人不出现 Cafe 下载源、汉化 UID 与资源面板入口；背景覆盖关闭时继承全局默认。
- 迁移：旧单游戏 `settings.json` 与旧下载检查点只迁入蔚蓝档案；迁移后重新启动两款游戏仍能识别各自安装、任务与已读公告。
- 快捷键：`--launch-game --game-id blue-archive-jp` 与 `--launch-game --game-id stella-sora-cn` 命中对应游戏，裸 `--launch-game` 命中蔚蓝档案；未知或重复参数被拒绝。

## 下拉选择与菜单增补（2026-11-01）

- 明暗主题对照字段、弹出列表、游戏管理菜单、右键菜单和子菜单：圆角、行高、文字、边框、内缩一致；卸载保留危险文字，禁用项不可选择。 字段右侧使用 16 DIP `FAFontIcon#DropDownGlyph`，与其他展开指示保持同一图标家族；普通、焦点及禁用态随字段前景更新，不移动文字。
- 鼠标悬停／按下、打开／关闭及 Tab／方向键导航时，检查实际模板表面使用共享状态色，焦点不移动文字；Enter 提交，Escape 放弃，长列表继续滚动。
- 打开菜单后切换主题／动态配色，不残留旧底色；保留图标、快捷键、勾选状态及子菜单。截图对照 `choice-popup-light/dark` 和 `launch-split-menu`。
- Headless 以实际模板部件与原生键盘路径检查以上主要状态；真实 OS DPI、原生弹窗多屏避让及屏幕阅读器仍需人工走查。
- 选中下拉项与设置导航的静止／悬停／按下文字均 ≥4.5:1；下拉项焦点内缩 2 DIP、描边 2 DIP，与实际相邻容器填充 ≥3:1。切换主题和中性色策略时，已打开弹窗同步更新；Fidelity 红色焦点和蓝色悬停截图见 `choice-popup-fidelity-focus`／`choice-popup-fidelity-hover`。

### 统一操作面板与任务对话框（ADR-057）

- 隐藏可选状态栏后仍保留主操作和任务入口；主操作左侧不再显示操作摘要／会话文字，托盘仍显示启动中／运行中。
- 主动执行和自动续传都在拆分按钮上方显示固定紧凑卡片，无折叠／展开；四语言、亮暗主题和文字放大下保持右对齐与 16 DIP 间距，点击主操作返回卡片且不移动主按钮。
- ESC 不关闭非模态进度卡片；停止需确认，取消确认回到卡片，停止收尾完成前不能开始新任务。
- 前台可见结果原位保留，覆盖时通知一次，后台完成在恢复前台后通知一次；旧通知不得打开新任务结果。查看结果关闭普通覆盖层时仍保留草稿确认与关键模态闸口。
- 下载直接显示已下载大小／总大小及速度，支持暂停／继续；暂停保留大小并隐藏速度。校验显示文件计数，实际读取仍参与无进展检测；30 秒无推进只提示等待。主按钮随安装／更新／修复和暂停等状态变更，成功后手动开始游戏。停止、日志和适用的重试始终无需展开即可操作。
- 安装路径草稿关闭即放弃，显式安装／识别才保存；可见失败提供适用的重试与日志入口。
- 安装准备的下载量与所需空间以留白分组，不出现竖线／中点等字符分隔符（spec §1，契约 `ProductionMarkup_DoesNotUseGlyphSeparators` 锁定）。
