# Cafe Launcher design-system prototype

No frontend framework, generated imagery, or remote runtime dependency is used.

- [Dark home](home-dark.html)
- [Download progress](home-progress.html)
- [Light settings](settings-light.html)
- [Compact home](home-compact.html)

and the launcher background from `Assets/launcher-background.png`.
